## Mission 3 replacement — implementation summary

### Class 1 — Design for Heat Retention
Students retrieve conduction, convection and radiation from Mission 2, inspect available recycled materials, create a labelled thermos design and begin Prototype 1.

Preferred materials:
- one standardized inner cup/container per team
- ordinary/recycled insulation materials
- tape/string/elastics
- rulers

### Class 2 — Prototype Test
Teacher supplies **200 mL of hot-but-not-boiling water**. Students record temperature at **0, 5, 10, 15, 20, 25 and 30 minutes**.

Preferred materials:
- 4–6 shared thermometers
- plastic measuring containers
- trays/towels
- timers
- Prototype 1 thermoses

Safety:
- teacher controls heating/pouring
- no boiling water
- cups remain on desks/trays
- wet materials stay away from Chromebooks

### Class 3 — Evidence → Redesign
Students:
- calculate temperature change
- create a **time–temperature graph**
- diagnose conduction/convection/radiation
- propose two changes
- choose one or two evidence-based redesigns

Reasoning rule:

**CHANGE → HEAT-TRANSFER PROCESS → PREDICTED EFFECT**

### Class 4 — Final Test + JCEC Decision
Repeat the same test conditions as closely as practical. Compare Prototype 1 with the Final Design and decide which two thermal-design principles JCEC should carry forward.

A redesign that performs worse is still useful evidence.

## Mission 3 no-purchase / shared-equipment plan

You do **not** need one thermometer per team.

Preferred:
- 4–6 thermometers total
- staggered team starts
- pooled/shared data where useful

If only 1–2 thermometers are available:
- run a teacher measurement station
- stagger groups
- use teacher/class readings for missing intervals

If no usable thermometers are available:
- use supplied Prototype 1 + Final Design datasets
- students still graph, calculate temperature change, diagnose and evaluate redesign

If construction materials are unavailable:
- use Thermos Design Cards / paper layering
- use supplied matching datasets

No thermos kit, data logger or specialty insulation kit is required.

## Contingency playbook

### Limited thermometers
Stagger starts and pool data. One thermometer can still support a teacher-run quantitative test.

### Hot-water setup unavailable
Use supplied Prototype/Final datasets. Preserve graphing, diagnosis and redesign.

### Starting temperatures differ
Compare **temperature decrease**, not raw final temperature alone.

### Thermos leaks
Stop safely, record the design failure, repair if practical or use supplied data.

### Final design performs worse
Keep the evidence. Students explain why the redesign did not improve performance.

### Student absent during thermos test
Use team/class data; do not require a private hot-water retest.

### A class is lost
Use Day 12 FLEX. If necessary, combine analysis/redesign with a shorter standardized final test, but do not cut evidence reasoning.

### Mission 4 or Mission 5 runs long
Use the existing approved fallbacks; do not shift time away from Mission 3 evidence reasoning.
