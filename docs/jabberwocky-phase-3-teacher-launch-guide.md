# Jabberwocky: Mission 2190 — Phase 3 Teacher Launch Guide

## Phase 3 — SURVIVING JABBERWOCKY

**JCEC Thermal Survival Division**  
**18 core classes + 7 purposeful flex periods**

Mission pacing:
- Mission 1 — Read the Thermal Warning — **3 classes**
- Mission 2 — Follow the Heat — **3 classes**
- Mission 3 — Hold the Temperature — **4 classes**
- Mission 4 — Control the Habitat — **4 classes**
- Mission 5 — Survive Without Wasting It — **4 classes**

Total core time: **18 classes**.

## Standing implementation rule

Use this order before buying anything:

**ordinary classroom supplies → shared/reused equipment → printables/data fallbacks → specialty equipment only as optional enrichment**

The science target is the evidence and reasoning, not the apparatus.

## Core student products

- Mission 1 — **Thermal Risk Card** — formative
- Mission 2 — **Habitat Heat Map** — formative
- Mission 3 — **Thermal Barrier Recommendation** — stronger science-reasoning checkpoint
- Mission 4 — **Habitat Control Protocol** — formative
- Mission 5 — **JCEC Thermal Survival Plan** — major synthesis
- Optional — short **individual Heat & Temperature science check**

Suggested numeric balance when required:
- Mission 3 checkpoint — **30%**
- Mission 5 synthesis — **55%**
- Optional individual science check — **15%**

If the individual check is not used, approximately **35% checkpoint / 65% synthesis** is reasonable.

## Mission Materials Master List

### Mission 1 — Thermal Change Investigation + thermometer practice
Preferred:
- 4–6 shared thermometers for the class
- reused cups/containers
- room-temperature, cool and warm water
- ice
- bottle + balloon/flexible cover
- towels
- printed investigation + Thermal Risk Card

No-purchase fallback:
- rotate teams through 1–2 thermometers
- use teacher-provided temperature readings
- use supplied liquid/solid expansion evidence cards instead of specialty expansion apparatus

Specialty equipment such as probes is optional enrichment only.

### Mission 2 — Heat Pathway Stations
Preferred:
- cups and warm water
- metal/plastic/wood utensils or strips
- optional food colouring
- dark/light or exposed/shaded surfaces
- shared thermometers where useful
- sunlight or an existing lamp where useful
- printed Heat Pathway station sheet + Habitat Heat Map

No-purchase fallback:
- teacher demonstration + observation/data cards for conduction, convection and radiation

Do not require infrared cameras, thermal imagers or commercial heat-transfer kits.

### Mission 3 — Thermal Barrier Fair Test
Preferred:
- matched reused cups/containers
- 4–6 shared thermometers
- warm water
- equal-size barrier samples already available: paper, cardboard, fabric, foil, bubble wrap, etc.
- timer
- towels
- graph template + Thermal Barrier Recommendation

No-purchase fallback:
- one teacher-run station
- pooled class data
- JCEC backup dataset

### Mission 4 — Habitat Control Loop Challenge
Preferred:
- printed/projected temperature sequence
- response cards
- pencils
- optional existing thermometer or bimetal-strip demonstration

No-purchase fallback:
- project all information and have teams respond on notebook paper

No electronics or purchased thermostat equipment are required.

### Mission 5 — Thermal Technology Briefing + Energy Budget Challenge
Preferred:
- printed/cached authentic source cards
- printed/projected continent scenarios
- paper energy tokens or tally sheet
- Thermal Evidence Locker
- JCEC Thermal Survival Plan

No-purchase fallback:
- project one set for the room and use notebook paper

No specialty thermal equipment is required.

## Thermometer-sharing plan

You do **not** need one thermometer per team.

Preferred classroom model:
- 4–6 thermometers total
- 1–2 thermometers at each shared station
- teams rotate through measurement windows
- class data is pooled

If only 1–2 thermometers are available:
- run a teacher measurement station
- give the rest of the class the remaining readings/data cards

Thermometers are mainly needed in Missions 1–3. Missions 4–5 can run without them.

## Contingency playbook

### Limited thermometers
Use station rotation and pooled data. If only 1–2 are available, run a teacher station and provide the remaining readings.

### Missing station materials
Replace the missing physical setup with the prepared observation/data card. Preserve the reasoning question.

### Convection demonstration fails
Use the liquid-convection evidence card plus the air-as-fluid visual. Do not buy replacement apparatus.

### Radiation station gives little temperature difference
Use the sample dataset. Classroom light/weather can be weak or inconsistent.

### Fair-test data is noisy or contradictory
Keep the data. Ask students to identify possible uncontrolled variables, compare with pooled/backup data, and state uncertainty.

### Student absent during an investigation
Give the student the class dataset/evidence card plus the same reasoning prompts. A physical repeat is not required.

### A class is lost
Use the nearest flex period. Cut whole-class sharing, optional demos and artistic polish before cutting the decision/Team Record.

### Control Loop Challenge runs long
Use fewer readings but preserve one too-cold, one safe-range and one too-warm condition.

### Thermal Energy Budget Challenge runs long
Use three rounds instead of four, reveal the consequence, require one revision, then move to the Evidence Locker.

### Source websites are unavailable
Use the printed/cached Natural Resources Canada source cards already provided in Mission 5. Live browsing is not required.

## Alberta Grade 7 Heat & Temperature alignment

The teacher system and student system use the same existing Alberta Science 7–9 Program of Studies baseline.

Coverage:
- **temperature measurement / thermometer use** → Mission 1
- **heat vs temperature / particle model** → Mission 1
- **expansion / contraction / changes of state** → Mission 1
- **conduction / convection / radiation** → Mission 2
- **conductivity / insulation** → Mission 3
- **fair testing / controlled variables / quantitative data / graphing / discrepancies** → Mission 3
- **passive and active solar** → Mission 4
- **thermal-energy sources** → Missions 4–5
- **thermometers / thermostats / feedback** → Missions 1 and 4
- **heating / cooling systems** → Mission 4
- **historical thermal technology** → Mission 4 Then → Now strip
- **safety** → Missions 1, 4 and 5
- **energy use / renewable-non-renewable considerations** → Mission 5
- **conservation / environmental consequences** → Mission 5
- **evidence-based decisions** → Mission 3 checkpoint + Mission 5 synthesis

Official source: https://education.alberta.ca/media/159716/sci7to9.pdf

Keep outside the required Grade 7 pathway:
- advanced calorimetry
- specific-heat calculations
- gas laws
- detailed refrigeration cycles
- formal efficiency equations
