# Jabberwocky Phase 4 — Project New Horizon Teacher Launch Guide

## Unit structure

- Mission 1 — Read the Building Site — 3 classes — formative
- Mission 2 — Trace the Forces — 3 classes — formative
- Mission 3 — Choose What Holds — 4 classes — stronger structural-science checkpoint
- Mission 4 — Keep It Standing — 4 classes — formative
- Mission 5 — Authorize New Horizon — 4 classes — major synthesis

Total: **18 core classes + 7 purposeful flex periods = 25 classes**.

## Integrated CityScape rule

The approved **Project New Horizon — JCEC CityScape Field File** is the physical project thread across the existing five Science missions. It does **not** replace the Science sequence or create a second Science assessment system.

- **Mission 1 — DEFINE:** teams establish the district requirements and begin the three-building CityScape concept. The **New Horizon Requirements Card** remains the Science Team Record.
- **Mission 2 — ANALYZE:** teams return to one chosen **Primary Structural Test Building** and complete its **Structural Force Map**.
- **Mission 3 — CHOOSE:** teams run the existing fair material/joint investigation, load-versus-deformation graph and **Material & Joint Recommendation** before committing structural choices.
- **Mission 4 — TEST & IMPROVE:** the Primary Building is the default test object when a fair comparison is possible: baseline → weakness → two alternatives → choose → modify → retest → **New Horizon Safety Protocol + Final Build Readiness**. The existing **Standardized Stability & Improvement Investigation** / fallback dataset is a contingency when team-built models are too different for a controlled comparison, not a second required build.
- **Mission 5 — DEFEND:** the completed CityScape district becomes an evidence object for the Design Review and **JCEC New Horizon Structural Authorization**. **No new physical build is required.** Phase 4 authorizes a structural proposal; it does not make the final Mission 2190 settlement decision.

### Math runs alongside Science

The Field File deliberately contains three **individual Math evidence pages**: **Page 3 — Building Geometry; Page 6 — Geometric Constructions / measured blueprint work; Page 10 — Resource Mathematics.** These are completed in Math time or other deliberately scheduled cross-curricular time. They do not turn the Science mission pages into Math lessons and do not add periods to the **18 core + 7 flex Science schedule**.

## Standing low-material rule

**ordinary classroom supplies → shared/reused equipment → printables/data fallbacks → specialty equipment only as optional enrichment**

No class set of spring scales, no structural kits, no large craft-stick purchases, no hot glue, no saws, no utility knives, and no large final physical structure are required.

## Shared-equipment plan

A single spring-scale / force-measurement station is enough. If 1–3 scales are available, rotate teams through the station while others complete internal-force tasks. If none are available, use the supplied mass/force readings and teacher demonstration. The goal is to distinguish g/kg from N and reason from force evidence, not to purchase one scale per group.

### Mission 2 — Force Pattern Stations
Preferred: string, paper/card, stacked cards, ruler/cardboard strip, clips, small safe objects, optional sponge/foam already on hand.
Fallback: internal-force observation cards.

### Mission 2 — spring-scale / force-measurement station
Preferred: 1–3 shared spring scales if the school already owns them.
Fallback: teacher demonstration or supplied force data. A class set is unnecessary.

### Mission 3 — Material & Joint Fair Test
Preferred: equal-size paper/cardstock, recycled cardboard, recycled plastic if available, rulers, small safe masses, binder clips, tape.
Fallback: teacher demonstration + supplied load/deformation dataset.

### Mission 3 — load-versus-deformation graph
Preferred: pooled class data + simple graph template.
Fallback: teacher-generated graph for interpretation if graphing time is lost.

### Mission 3 — fixed/flexible Joint Check
Preferred: simple paper/tape/clip models.
Fallback: evidence cards.

### Mission 3 — Nature's Materials
Use the short evidence strip already on the student page: bone, cartilage, ligament and plant tissues/layers. Keep it brief.

### Mission 4 — Primary Building Stability & Improvement Investigation
Preferred: the team's Primary Structural Test Building plus the same safe disturbance/load setup used for baseline and retest; small loads and limited improvement materials as needed.
Fallback: **Standardized Stability & Improvement Investigation** using a shared reference model, baseline-model photos/data + stability comparison dataset + before/after strengthening evidence. Apply the resulting stability principle back to the team CityScape.

### Mission 5 — JCEC Structural Design Review
Preferred: completed CityScape district, printable/projected Structural Design Toolkit, six-part Design Review Matrix, Evidence Locker, pencils.
Fallback: project the toolkit and use notebook paper plus photographs/sketches/packet evidence if the physical district is unavailable.

### Mission 5 — Structural Authorization
Preferred: Field File Page 14, **JCEC New Horizon Structural Authorization**.
Fallback: copy the headings onto notebook paper.

## Contingency playbook

- **No spring scale available:** use supplied mass/force readings or one teacher demonstration.
- **Missing station materials:** replace with matching evidence cards.
- **Noisy/contradictory material-test data:** retain the data, pool class results, compare with backup data, and discuss possible uncontrolled variables.
- **Uneven material samples:** pre-trim a standardized set or use the backup dataset; do not treat an unfair test as valid evidence.
- **Student absent during investigation:** use class/backup data and complete the same reasoning task; do not recreate a private full lab.
- **A class is lost:** cut presentations, extra examples and polish before cutting the scientific decision or Team Record.
- **Mission 3 testing runs long:** test fewer materials/loads and pool evidence.
- **Graphing takes too long:** provide a teacher-generated/partially completed graph and assess interpretation.
- **Primary Building models are not comparable enough for a fair Mission 4 test:** run the standardized reference model or fallback dataset, then require students to apply the stability result to their own Primary Building.
- **A model fails too early:** stop safely and use shared/fallback evidence; do not encourage repeated destruction.
- **Students compete for maximum load:** stop at the posted test ceiling and redirect to evidence/reasoning; there is no strongest-model prize.
- **Mission 4 modify/retest runs long:** provide two improvement choices and supplied retest evidence if necessary.
- **Mission 5 Design Review runs long:** narrow the toolkit and move final prose to Flex Day 22.
- **Printing/device failure:** project shared materials or use notebook paper.

## Alberta Structures & Forces alignment

Use the existing Alberta Science 7–9 Program of Studies, Unit D: Structures & Forces:
https://education.alberta.ca/media/159716/sci7to9.pdf

Coverage across the five missions includes:

**function/performance requirements → frame/shell/frame-and-shell → same-function design variation → natural structures → structures from different cultures/times → failure points → mass vs force units → loads → friction → tension → compression → shearing → bending → strength → flexibility → stiffness/deformation → controlled material testing → fixed/flexible joints → natural/synthetic materials → structural materials in plants/animals → mass distribution → foundations → stability → corrugation → lamination → component shape → fastening/bracing → environmental factors → margin of safety → prototype alternatives → modification/retesting → troubleshooting → quantitative/qualitative evidence → tables/graphs → function/reliability/safety/material efficiency/cost-environment trade-offs → evidence-based structural decisions.**

Keep outside the required pathway:

**formal stress/strain equations → torque calculations → beam mathematics → numerical safety-factor calculations → advanced engineering economics → torsion as a required fifth internal-force type.**

## Teacher launch-readiness audit

- Do I know what to prepare tomorrow? **Yes — every core day uses a fixed preparation field on the live guide.**
- Do I know what students should finish each day? **Yes — each day identifies collect/assess evidence and the approved Field File identifies the official record.**
- Do I know when spring scales/shared materials are actually needed? **Yes — Mission 2 only; one station or supplied data is enough.**
- Can I run the whole unit without buying specialized equipment? **Yes — all investigations have no-purchase fallbacks.**
- Do I know what is formative, checkpoint and major assessment? **Yes — M1/M2/M4 formative, M3 checkpoint, M5 synthesis; the three Math pages remain separate Math evidence.**
- Can I recover if a test, model or class goes wrong? **Yes — contingency playbook + seven flex periods.**
- Do Mission 3 and Mission 4 remain different? **Yes — M3 tests components/materials; M4 tests whole-system stability and improvement on the Primary Building or reference fallback.**
- Does this stay science-first rather than competition-first? **Yes — fair tests, teacher test ceilings, evidence-based rubrics and a one-Primary-building workload rule.**
- Do teacher and student systems match? **Yes — five missions, 18 core classes, seven flex periods, approved packet records and one final Structural Authorization.**
