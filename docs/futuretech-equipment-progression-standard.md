# FutureTech Equipment Progression Standard

**Status:** INTERNAL COURSE STANDARD — pre-Mission 7 planning  
**Applies to:** FutureTech Lab Levels 1–5  
**Progression model:** mastery-based, not term-based  
**Protected content:** does not modify frozen Missions 1–6 or authorize Mission 7 implementation

---

# 1. Purpose

FutureTech equipment access should grow with demonstrated student independence.

The progression is not:

> **new term → new equipment**

It is:

> **demonstrated skill → appropriate access → increased responsibility**

A student may remain on familiar equipment while strengthening a skill, and a returning student may continue from the highest level they have already demonstrated.

Equipment access is earned through:

- safe setup and reset;
- independent project ownership;
- troubleshooting before teacher intervention;
- accurate use of the tool;
- successful checkpoint evidence;
- responsible handling of shared equipment;
- appropriate file/project management;
- ability to explain what the tool is doing and why.

This standard separates:

1. **course level** — the kind of work a student is ready to attempt;
2. **equipment authorization** — the specific equipment the student is ready to use.

Reaching a level does not automatically authorize every machine in that level.

---

# 2. Core access rule

Use this progression:

**LEARN → DEMONSTRATE → EARN ACCESS → USE RESPONSIBLY → RETAIN ACCESS**

Students retain access only while they continue to:

- follow safety expectations;
- use equipment for the approved task;
- reset equipment correctly;
- report faults honestly;
- avoid bypassing queue or teacher controls;
- work within the approved project scope.

Unsafe or careless use may temporarily return a student to a more supported access level without changing the student's broader course mastery record.

FutureTech uses five equipment categories.

## B. Game-control tools

- Kitronik :GAME Controller for BBC micro:bit

## C. Plug-and-play robotics

- Hummingbird Bit Robotics Kits

- rotation servos
- light sensor

## D. Physical-computing / electronics

- Kitronik Inventor’s Kit for BBC micro:bit
- breadboard
- resistors
- LEDs
- switches
- potentiometer
- phototransistor / light sensing
- transistor

- Autodesk Tinkercad

> **E3-01 / E3-02 = beginner production printers**

# 4. Level 1 — Creator Foundations

## Purpose

Learn the core tools and routines.

Level 1 answers:

> **Can I use the tools safely, follow a workflow, troubleshoot basic problems and explain what I made?**

## Student tools

### Coding

- MakeCode
- micro:bit V2

Students learn:

- events;
- sequence;
- variables;
- simple loops;
- randomness;
- IF / ELSE;
- download / test workflow;
- basic debugging.

### Game controllers

Use:

- Kitronik :GAME Controller; or
- ELECFREAKS Retro Arcade.

Students use one assigned path rather than needing to master both controllers.

Required responsibility:

- connect only as directed;
- stay on assigned controller path;
- test controls;
- return controller correctly;
- report faults instead of swapping equipment randomly.

### Hummingbird robotics

Level 1 core access:

- Bit Controller;
- single-colour LED;
- position servo;
- light sensor.

Level 1 concepts:

- code → port → output;
- sensor → value → threshold → decision → output;
- basic port identification;
- power-off / test-on routine;
- safe wiring;
- simple Sense → Think → Act systems.

Keep rotation servos, distance sensors, sound sensors and more complex multi-sensor systems out of the required Level 1 pathway.

### 3D design

Use:

- Tinkercad 3D Design;
- primitive shapes;
- exact dimensions;
- Align;
- Group;
- Hole;
- basic printability;
- STL export after checkpoint approval.

### Beginner 3D printers

Use:

- **E3-01**
- **E3-02**

Students do **not** operate the printers independently in Level 1.

Student responsibility ends at:

**approved CAD → approved STL → print queue**

Teacher controls:

- slicing;
- printer assignment;
- print start;
- nozzle / bed settings;
- supports;
- infill;
- layer height;
- printer troubleshooting.

Default material:

- **PLA**

ART-01 is not part of routine Level 1 access.

# 5. Level 1 authorization gate

Before a student can move into Builder-level equipment use, they should demonstrate the following across the Level 1 missions.

## Core maker habits

- ☐ Works independently by default.
- ☐ Uses TRY 4 before asking for teacher help.
- ☐ Saves projects with correct names.
- ☐ Can explain expected versus actual behaviour.
- ☐ Makes a small requested change independently.
- ☐ Completes Reset correctly.
- ☐ Reports faulty equipment rather than hiding or randomly swapping it.
- ☐ Uses Ready-for-Check appropriately.

## Coding

- ☐ Can use events, variables, loops and conditions.
- ☐ Can test and debug a simple program.
- ☐ Can explain input → code → output.

## Robotics

- ☐ Can safely connect Hummingbird components.
- ☐ Can match code to the correct Hummingbird port.
- ☐ Can use at least one sensor and one output.
- ☐ Can explain Sense → Think → Act.

## 3D design

- ☐ Can navigate Tinkercad.
- ☐ Can create an accurately dimensioned model.
- ☐ Can Align and Group shapes.
- ☐ Can use a Hole correctly.
- ☐ Can identify basic printability problems.
- ☐ Can submit one clean approved STL.

## Level 1 access earned

Successful Level 1 mastery authorizes entry to:

> **Level 2 — Builder equipment pathways**

It does **not** authorize ART-01 laser, CNC or advanced printing.

# 6. Level 2 — Builder

## Purpose

Build more capable systems using familiar tools plus introductory electronics.

Level 2 answers:

> **Can I combine several parts correctly and build a reliable working system?**

## micro:bit

Continue full access.

Increase expectations:

- multiple inputs / outputs;
- more variables;
- more complex conditions;
- functions where useful;
- structured testing;
- clearer project organization.

Students may begin transitioning from blocks toward JavaScript or Python only when instructionally appropriate.

Text coding is not required merely because a student reaches Level 2.

## Game controllers

Use as reusable prototyping inputs rather than as a standalone learning target.

Examples:

- custom controller schemes;
- multi-button games;
- controller-driven robotics or interfaces;
- more developed MakeCode Arcade projects.

Students should no longer need step-by-step controller setup directions.

## Hummingbird robotics

Builder access may expand to:

- tri-colour LED;
- multiple LEDs;
- multiple position servos;
- rotation servo;
- distance sensor;
- sound sensor;
- dial sensor;
- multiple simultaneous inputs / outputs.

Appropriate work:

- animatronics;
- reactive mechanisms;
- simple rovers;
- multi-state systems;
- sensor-controlled movement;
- more purposeful mechanical builds.

Required before rotation servo / rover-style access:

- safe wiring demonstrated;
- port-matching reliability;
- correct power routine;
- ability to stop or disable unexpected motion;
- independent troubleshooting of a simple Hummingbird system.

## Kitronik Inventor’s Kit — introductory access

Level 2 is the entry point for the Inventor’s Kit.

Students learn:

- breadboard orientation;
- power rails / connection logic as appropriate;
- LEDs with resistors;
- switches;
- potentiometer / analog input;
- light sensing;
- transistor-controlled motor;
- buzzer;
- jumper-wire discipline;
- reading a simple wiring diagram.

Core idea:

> **Hummingbird lets students use robotics components quickly. Inventor’s Kit begins showing what is happening electrically underneath.**

Level 2 electronics should remain low-voltage, low-hazard and strongly diagram-supported.

## 3D design

Tinkercad continues.

Students may add:

- more complex multi-shape models;
- repeated features;
- simple functional parts;
- measurement from a real object;
- simple enclosure / bracket / holder designs;
- revision after a failed print.

## 3D printing

Primary machines remain:

- E3-01
- E3-02

Students may begin learning selected teacher-facing fabrication concepts:

- orientation;
- why supports may be needed;
- why wall thickness matters;
- estimated print time;
- why a print may fail.

Printer start / calibration remains teacher controlled unless a later authorization gate specifically permits supervised operation.

ART-01 remains restricted.

# 7. Level 2 authorization gate

Before moving into Designer-level equipment access, students should demonstrate:

## Build reliability

- ☐ Can build a multi-component system from a diagram or plan.
- ☐ Can isolate a fault rather than randomly replacing parts.
- ☐ Can document one meaningful revision.
- ☐ Can maintain an organized workspace during a longer build.

## Robotics

- ☐ Can use more than one Hummingbird input/output appropriately.
- ☐ Can explain why each port/component is present.
- ☐ Can safely control motion.

## Electronics

- ☐ Can use a breadboard without creating unsafe or random connections.
- ☐ Can identify resistor, LED, switch, potentiometer and transistor roles at a basic level.
- ☐ Can follow and check a simple circuit diagram.
- ☐ Can distinguish a wiring problem from a coding problem.

## Fabrication

- ☐ Can revise a CAD model after a printability problem.
- ☐ Understands that orientation, thickness and geometry affect manufacturing.
- ☐ Submits clean files and follows the queue.

Successful Level 2 mastery authorizes:

> **Level 3 — Designer equipment combinations**

# 8. Level 3 — Designer

## Purpose

Choose and combine technologies intentionally.

Level 3 answers:

> **Can I select the right tools for a design and make the parts work together?**

## Coding

Students plan larger programs rather than building only from guided patterns.

Expect:

- named variables;
- functions where useful;
- reusable logic;
- planned inputs / outputs;
- test cases;
- documented revisions.

## Hummingbird robotics

Full classroom Hummingbird component access may be granted after the relevant Builder gate.

Students may design:

- multi-sensor systems;
- animatronics;
- interactive exhibits;
- controlled rovers;
- mechanisms with multiple servos;
- sensor-driven behaviours.

The teacher may still restrict components that are scarce or create unnecessary mechanical risk.

## Kitronik Inventor’s Kit

Designer-level use expands from following circuits to modifying them.

Students may:

- alter resistor/component choices within teacher-approved bounds;
- combine sensor + output circuits;
- use motor-driver / transistor concepts appropriately;
- prototype custom physical-computing interfaces;
- integrate breadboard electronics with a designed enclosure or mechanism.

Students should explain both:

**what the code does**  
and  
**what the circuit does**

## Tinkercad / CAD

Students may move beyond simple Maker Tags into functional design.

Appropriate concepts:

- fit;
- clearance;
- repeated features;
- basic tolerances;
- mounting holes;
- brackets;
- enclosures;
- component holders;
- prototypes designed from measured physical objects.

Tinkercad remains acceptable if it can solve the task.

A more advanced CAD platform may be introduced later if the project genuinely requires it; tool difficulty is not itself a reason to switch.

## E3-01 / E3-02

Students may earn **supervised production access**.

Possible authorized responsibilities:

- load an already approved file/profile;
- confirm the correct printer/file;
- perform a teacher-approved pre-print checklist;
- start a teacher-approved PLA job;
- monitor the first layers;
- report a failure.

Teacher still controls maintenance, calibration changes and unsafe troubleshooting.

## ART-01 — first restricted access

Level 3 is the earliest point at which ART-01 may be introduced for **advanced 3D printing only**, and only after a separate authorization.

This does not include laser or CNC.

Possible ART-01 Level 3 use:

- supervised single-material 3D printing;
- larger functional prototypes where size is genuinely necessary;
- teacher-approved batch work;
- introduction to dual-extrusion concepts through demonstration or tightly controlled use.

ART-01 access is not automatic for every Level 3 student.

---

# 9. ART-01 3D-print authorization gate

Before a student may directly participate in an ART-01 3D-printing workflow, require:

- ☐ Level 1 CAD mastery.
- ☐ Level 2 printability / revision mastery.
- ☐ Consistent file naming and queue discipline.
- ☐ Correct use of E3-01 / E3-02 workflow.
- ☐ Can explain orientation, support need and print-time tradeoffs at a basic level.
- ☐ Can complete a printer-specific preflight checklist without skipping steps.
- ☐ Demonstrates careful behaviour around hot and moving equipment.
- ☐ Follows teacher stop / abort directions immediately.

Authorization level:

> **ART-01 3D PRINT — SUPERVISED**

This does not authorize laser or CNC.

# 10. Level 4 — Engineer

## Purpose

Design integrated systems that solve a defined problem.

Level 4 answers:

> **Can I engineer a reliable solution, justify my choices and use advanced equipment safely?**

## Coding / control systems

Students may use:

- larger state-based programs;
- functions;
- multiple sensors;
- data logging;
- radio communication;
- coordinated subsystems;
- more advanced debugging.

Text-based coding may become more common when it improves the project.

## Robotics

Students may integrate:

- Hummingbird;
- custom electronics;
- mechanical structures;
- fabricated parts;
- multiple sensor types;
- multiple motion outputs.

Projects should move toward engineering constraints such as:

- reliability;
- repeatability;
- accuracy;
- maintainability;
- user interaction.

## Inventor’s Kit / electronics

Students may create more independent breadboard prototypes within teacher-approved low-voltage limits.

Appropriate concepts:

- analog vs digital input;
- transistor switching;
- component selection from approved inventory;
- circuit debugging;
- measured testing;
- interface design;
- custom control panels / sensors.

No mains-voltage work.

## Advanced 3D printing on ART-01

Students with ART-01 3D-print authorization may progress to:

- dual-colour / dual-material concept work;
- support material where appropriate;
- larger prototypes when justified;
- more complex assemblies;
- advanced material demonstrations when teacher-approved.

Material access remains teacher-controlled.

## ART-01 laser — supervised advanced authorization

Laser is an **Engineer-level or later** capability.

It requires a separate safety authorization.

Appropriate uses:

- engraving labels / graphics;
- cutting teacher-approved sheet materials;
- creating panels, templates, enclosures or structural parts;
- combining laser-cut components with robotics/electronics.

The Artisan enclosure, door detection and emergency-stop systems support safer supervised use, but they do not replace teacher supervision or school safety procedures.

## ART-01 CNC — supervised advanced authorization

CNC is also **Engineer-level or later** and requires a separate authorization.

Appropriate uses:

- teacher-approved wood/acrylic parts;
- simple pockets / profiles;
- fixture or enclosure components;
- projects where CNC is genuinely more appropriate than 3D printing or laser cutting.

CNC access should begin with highly constrained jobs and approved materials.

---

# 11. ART-01 laser authorization gate

Before student participation in laser workflows:

- ☐ ART-01 3D-print authorization already earned.
- ☐ Completes teacher laser safety instruction.
- ☐ Understands enclosure / door-interlock expectations.
- ☐ Can identify emergency-stop procedure.
- ☐ Uses only teacher-approved materials.
- ☐ Can explain why an unknown material must never be cut/engraved.
- ☐ Can identify fire / smoke / ventilation concerns.
- ☐ Can follow the approved file → preview → setup → supervised-run workflow.
- ☐ Never leaves an active laser job unattended.
- ☐ Stops immediately when instructed.

Authorization:

> **ART-01 LASER — TEACHER-SUPERVISED ONLY**

This standard does not authorize unsupervised laser use.

---

# 12. ART-01 CNC authorization gate

Before student participation in CNC workflows:

- ☐ ART-01 3D-print authorization already earned.
- ☐ Completes teacher CNC safety instruction.
- ☐ Can identify clamping / workholding requirements.
- ☐ Understands why loose workpieces are unsafe.
- ☐ Uses only teacher-approved stock and cutting tools.
- ☐ Can explain toolpath preview at a basic level.
- ☐ Can identify emergency-stop procedure.
- ☐ Keeps hands/tools clear during machine motion.
- ☐ Never changes bit, workholding or machine setup without teacher approval.
- ☐ Never leaves an active CNC operation unattended.

Authorization:

> **ART-01 CNC — TEACHER-SUPERVISED ONLY**

This standard does not authorize unsupervised CNC use.

---

# 13. Level 5 — Innovator

## Purpose

Select technologies based on the needs of an original project.

Level 5 answers:

> **Can I define a problem, choose the right tools, plan safely, build, test and iterate with increasing independence?**

Students do not use every tool simply because they are Level 5.

They choose only what the project requires.

Possible combinations:

- micro:bit + Hummingbird + custom enclosure;
- Inventor’s Kit electronics + fabricated control panel;
- game controller + robotics;
- sensor system + data display;
- dual-extrusion printed assembly;
- laser-cut structure + Hummingbird robotics;
- CNC component + electronics;
- multi-process ART-01 project;
- 3D printing + laser + CNC where each process has a justified role.

## Level 5 equipment expectations

Students may have access to all equipment for which they hold the specific authorization.

They still require:

- teacher approval of project scope;
- teacher approval of materials;
- supervised ART-01 laser/CNC operation;
- compliance with school safety procedures;
- queue / booking discipline;
- documented testing and revision.

Level 5 means **greater decision-making responsibility**, not unrestricted machine access.

# 15. Authorization is granular

Do not use one generic “Snapmaker certified” status.

Track separate authorizations:

- **ART-01 3D PRINT — SUPERVISED**
- **ART-01 LASER — SUPERVISED**
- **ART-01 CNC — SUPERVISED**

A student may earn one without the others.

Similarly, a student who is strong in coding but has not demonstrated breadboard safety should not automatically receive independent Inventor’s Kit access.

---

# 16. Returning-student rule

At the beginning of a new term:

1. check the student's last completed mastery level;
2. confirm equipment authorizations still apply;
3. run a short re-entry safety / equipment check when needed;
4. continue from the appropriate level.

Do not force returning students to restart Level 1 simply because a new term has begun.

Do not automatically advance returning students because of age or time spent in the course.

---

# 17. Temporary access restrictions

Equipment authorization may be temporarily reduced when a student:

- ignores a safety instruction;
- bypasses the queue;
- uses the wrong equipment without approval;
- repeatedly fails to reset/return equipment;
- makes unapproved wiring changes;
- uses unknown material in a fabrication workflow;
- leaves an active machine unsupervised;
- conceals equipment damage.

Response should be specific to the equipment/routine involved.

Example:

> A student may retain Level 3 coding/robotics status while temporarily losing supervised ART-01 access until the relevant safety check is repeated.

Do not erase unrelated demonstrated mastery.

---

# 18. Teacher role

The teacher remains responsible for:

- determining when evidence is sufficient for authorization;
- deciding when shared equipment is available;
- approving higher-risk materials/processes;
- maintaining printer / laser / CNC safety procedures;
- establishing local school/district safety requirements;
- stopping any process that appears unsafe;
- restricting equipment beyond this standard when conditions require it.

This standard sets the **minimum FutureTech progression**, not a guarantee of machine access.

---

# 19. Student-facing simplification

Students do not need the entire authorization document.

Student-facing language can remain:

> **Learn the tool → prove the skill → earn more access.**

Equipment badges/passport entries may eventually show:

- micro:bit Ready
- Hummingbird Ready
- Electronics Ready
- CAD Ready
- Ender-3 Production Ready
- ART-01 3D Print Ready
- ART-01 Laser Ready
- ART-01 CNC Ready

Do not award advanced badges based only on watching a demonstration.

# 20. FutureTech progression summary

## Level 1 — Creator Foundations

**Learn the tools.**

micro:bit + game controllers + basic Hummingbird + Tinkercad + teacher-managed E3-01/E3-02 printing.

## Level 2 — Builder

**Build with the tools.**

Expanded Hummingbird + introductory Inventor’s Kit electronics + functional CAD + deeper printability understanding.

## Level 3 — Designer

**Combine the tools.**

Independent component choices + modified circuits + functional CAD + supervised E3 production + possible ART-01 3D-print authorization.

## Level 4 — Engineer

**Solve with the tools.**

Integrated systems + advanced electronics/fabrication + ART-01 dual-extrusion + separate supervised laser/CNC authorizations.

## Level 5 — Innovator

**Invent with the tools.**

Original long-term projects using only the technologies that fit the problem, with all advanced fabrication governed by the specific authorizations already earned.

---

# 21. Locked philosophy

FutureTech equipment progression is:

> **mastery-based access, not age-based access**  
> **earned independence, not automatic privilege**  
> **tool choice based on project need, not novelty**  
> **advanced equipment requires advanced responsibility**

The Ender-3 printers remain the normal beginner fabrication platform.

The Snapmaker Artisan remains the advanced multi-process fabrication platform.

Mission 7 is not designed or authorized by this document.
