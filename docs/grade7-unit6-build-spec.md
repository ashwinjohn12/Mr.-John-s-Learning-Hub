# Grade 7 Math Unit 6 — Equations

Approved sequence: 6.1 Solving Equations; 6.2 Using a Model to Solve Equations; 6.3 Solving Equations Involving Integers; 6.4 Solving Equations Using Algebra; 6.5 Using Different Methods to Solve Equations.

Alberta alignment: PR3 preserve equality concretely, pictorially, and symbolically; PR4 distinguish expressions and equations; PR5 evaluate expressions by substitution; PR6 model and solve `x + a = b` with integer constants; PR7 model and solve `ax + b = c`, `ax = b`, and `x/a = b` with approved whole-number constants. Achievement evidence includes modelling, explaining equality-preserving moves, solving, substituting to verify, comparing methods, and translating contexts into equations.

Architecture: five ten-section lessons, five-phase lesson-specific Explore systems, eight supported items and 30 independent items per lesson, three-item exits, independently validated Apply tasks, a 20-item mixed review, ten misconception repairs, 40-item balanced Unit Check, and five-stage dependent Equation Rescue Arcade. Written evidence is recorded but never mechanically graded.
