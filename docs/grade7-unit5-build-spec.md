# Grade 7 Math Unit 5 — verified build specification

**Approved unit:** Unit 5, *Operations with Fractions*.

**Sequence:** 5.1 Using Models to Add Fractions; 5.2 Using Other Models to Add Fractions; 5.3 Using Symbols to Add Fractions; 5.4 Using Models to Subtract Fractions; 5.5 Using Symbols to Subtract Fractions; 5.6 Adding With Mixed Numbers; 5.7 Subtracting With Mixed Numbers.

**Alberta outcome N5:** Demonstrate an understanding of adding and subtracting positive fractions and mixed numbers, with like and unlike denominators, concretely, pictorially, and symbolically (limited to positive sums and differences).

**Achievement indicators:** model addition and subtraction with concrete and pictorial representations and record symbolically; determine sums and positive differences with like and unlike denominators; add and subtract mixed numbers; simplify answers; use benchmarks to estimate; solve and explain contextual problems using appropriate representations.

**Progression:** equal parts and equivalence → same-model addition → alternate linear/set models → efficient symbolic addition → modelled subtraction → efficient symbolic subtraction → mixed-number addition → mixed-number subtraction with regrouping. Grade 6 fraction equivalence and Unit 3 rational-representation fluency are prerequisites.

**Pacing:** two 35–40 minute core sessions per lesson. Session 1 uses readiness, two essential Understand cards, one worked example, Predict/Build, and two supported questions. Session 2 uses Verify, one further example, two supported questions, Check Yourself, and exit ticket. Repair/Create, remaining practice, and Apply are consolidation or extension.

**Representation path:** fraction strips and region models establish equal-sized parts; number lines, sets, and measurement contexts broaden meaning; common-denominator symbols compress the model; mixed-number models make composing/decomposing wholes visible. Contexts use length, recipes, time, and materials without replacing exact fraction reasoning.

**Explore/Apply:** each lesson has a distinct fraction tool with Predict, Build, Verify, Repair, and Create. Apply tasks independently validate estimates, exact calculations, simplest form, labelled model quantities, units, comparisons, reasonableness, and decisions. Changing a dependency invalidates all later evidence.

**Assessment:** each lesson has a unique readiness item, eight supported items, a separate 30-item Check Yourself bank, and three exit items. The review adds 20 mixed items, ten misconception repairs, and a separate 40-item Unit Check whose ten-item attempts include all seven lessons and three distinct lessons twice. Every incorrect result routes to the exact Understand heading.

**Accessibility/responsiveness:** keyboard-operable tabs and controls; focus recovery; status announcements; text transcripts for every model; feedback never relies on colour; 44 px targets; reduced-motion rules; single-column reflow and no essential horizontal scrolling at 390, 375, and 320 px.
