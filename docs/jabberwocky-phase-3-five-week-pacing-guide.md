## Core pacing total

- Mission 1 — **3 classes**
- Mission 2 — **3 classes**
- Mission 3 — **4 classes**
- Mission 4 — **4 classes**
- Mission 5 — **4 classes**

**Total = 18 core classes.**

## Mission 3 four-class sequence

1. **Design for Heat Retention** — conduction/convection/radiation application → labelled design → Prototype 1.
2. **Prototype Test** — teacher-controlled safe hot water → 200 mL → readings at 0, 5, 10, 15, 20, 25 and 30 minutes.
3. **Evidence → Redesign** — calculate temperature decrease → time–temperature graph → thermal diagnosis → two possible changes → redesign.
4. **Final Test + JCEC Decision** — repeat comparable procedure → Prototype vs Final → two transferable thermal-design principles → **JCEC Thermos Design Report**.

## Flex priorities

1. Recover evidence needed for Mission 3 checkpoint or Mission 5 synthesis.
2. Support absent students without forcing private hot-water lab repeats.
3. Reteach core Heat & Temperature misconceptions.
4. Complete the optional individual science check if useful.
5. Finish final synthesis.
6. Gallery walk/presentation only if core work is secure.
7. Preserve a final buffer for normal school interruptions.

## Equipment timing

### Thermometers/shared physical equipment needed most
- Days 1–2 — Mission 1 measurement/change evidence
- Days 4–5 — Mission 2 stations where quantitative evidence helps
- Days 9 and 11 — Mission 3 Prototype + Final thermos tests

### Mission 3 additional shared materials
- same inner cup/container per team
- recycled insulation materials
- plastic measuring containers
- safe teacher-controlled hot water
- shallow trays/towels
- graph paper/templates

### Mostly printable/projectable
- Days 13–16 — Mission 4 Control Loop / sources / protocol
- Days 18–21 — Mission 5 source cards / energy budget / Evidence Locker / final plan

## No-purchase recovery rule

When apparatus or time fails, preserve the same **evidence → reasoning → decision** task.

Mission 3 fallbacks, in order:
1. stagger shared thermometers
2. teacher measurement station
3. pooled class data
4. supplied Prototype/Final datasets
5. Thermos Design Cards if construction materials are unavailable

## Assessment checkpoints

- Days 1–6 — formative evidence only
- Day 11/12 — **Mission 3 JCEC Thermos Design Report — stronger science-reasoning checkpoint**
- Day 17 or 23 — optional individual science check
- Day 21/22 — **Mission 5 major Phase 3 synthesis**

Suggested weighting:
- Mission 3 — **30%**
- Mission 5 — **55%**
- Individual science check — **15%**

Without the individual check, use approximately **35% Mission 3 / 65% Mission 5**.
