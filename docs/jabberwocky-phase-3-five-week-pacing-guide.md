## Core pacing total

- Mission 1 — **3 classes**
- Mission 2 — **3 classes**
- Mission 3 — **4 classes**
- Mission 4 — **4 classes**
- Mission 5 — **4 classes**

**Total = 18 core classes.**

## Flex priorities

Flex time is not filler. Use it in this order:

1. Recover science evidence needed for Mission 3 checkpoint or Mission 5 synthesis.
2. Support absent students without forcing full physical lab repeats.
3. Reteach core Heat & Temperature misconceptions.
4. Complete the optional individual science check if useful.
5. Finish final synthesis.
6. Gallery walk/presentation only if the core work is secure.
7. Preserve a final buffer for normal school interruptions.

## Equipment timing

### Thermometers/shared physical equipment needed most
- Days 1–2 — Mission 1 measurement/change evidence
- Days 4–5 — Mission 2 stations when quantitative evidence is useful
- Days 8–10 — Mission 3 fair test and pooled class data

### Mostly printable/projectable
- Days 13–16 — Mission 4 Control Loop / sources / protocol
- Days 18–21 — Mission 5 source cards / energy budget / Evidence Locker / final plan

## No-purchase recovery rule

When apparatus or time fails, use the teacher-provided observation/data card or pooled class dataset. Students should still complete the same **evidence → reasoning → decision** task.

## Assessment checkpoints

- Days 1–6 — formative evidence only
- Day 11 — **Mission 3 stronger science-reasoning checkpoint**
- Day 17 or 23 — optional individual science check
- Day 21/22 — **Mission 5 major Phase 3 synthesis**

Suggested weighting when numeric grades are needed:
- Mission 3 — **30%**
- Mission 5 — **55%**
- Individual science check — **15%**

Without the individual check, use approximately **35% Mission 3 / 65% Mission 5**.

## Stop point

No Phase 4 student content is part of this pacing guide.
