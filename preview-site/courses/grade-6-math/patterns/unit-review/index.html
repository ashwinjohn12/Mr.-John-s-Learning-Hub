PAT-STYLE REASONING

Explain the relationship

8.1

A table repeats output 7 for inputs 2 and 4. Is that enough to make it not a function?

Strong answer

No. Different inputs may share the same output. It only fails to be a function if one input has two different outputs.

8.2

A graph shows (4,8), but the equation is y=2x+1. Explain the mismatch.

Strong answer

Substituting x=4 gives y=9, so the plotted point should be (4,9). The graph and equation do not currently represent the same function.

8.3

A fare follows y=3x+5. Explain how to find x if the fare is $32.

Strong answer

Work backward: 32−5=27, then 27÷3=9. Verify by substituting x=9: 3(9)+5=32.

WHOLE-UNIT SYNTHESIS

One function: y = 4x + 3

  1. Explain which variable is independent and dependent.
  2. Make three input-output pairs.
  3. Describe how those pairs would appear in a table and graph.
  4. Find y when x=6.
  5. Find x when y=35 and verify it.
Show a strong solution

x is the independent/input variable and y is the dependent/output variable. Example pairs are (0,3), (1,7), and (2,11). The table lists those pairs and the graph plots those same coordinates. For x=6, y=27. For y=35: 35=4x+3, so 32=4x and x=8. Check: 4(8)+3=35.
