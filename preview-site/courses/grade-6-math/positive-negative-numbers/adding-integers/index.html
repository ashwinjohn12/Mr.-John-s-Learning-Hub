Adding Integers

Move from models to efficient symbolic strategies for adding integers.

START HERE

The big idea

The models from Lesson 1.2 lead to efficient symbolic strategies for adding integers.

The models from Lesson 1.2 show a pattern. If the signs are the same, both addends move in the same direction: add the magnitudes and keep the sign. If the signs are different, opposite parts cancel: find the difference between the magnitudes and use the sign of the number farther from zero. You can also break an addend apart to make a zero pair.

Think about itWhy does (+6) + (−10) have the same result as (+6) + (−6) + (−4)?
📘

LEARN

Build your understanding

01

Same signs: combine the magnitudes

If both integers are positive, the sum is positive. If both are negative, the sum is negative. Add the magnitudes because both addends move in the same direction.

Remember: (−7) + (−5): add 7 + 5 = 12 and keep the negative sign, so the sum is −12.

02

Different signs: compare the magnitudes

When one addend is positive and the other is negative, the opposite parts cancel as zero pairs. Subtract the smaller magnitude from the larger magnitude.

Remember: The sign of the sum matches the addend with the greater magnitude.

03

Decompose to make zero

Break one addend into two parts so one part is the additive inverse of the other addend. For (+6) + (−10), rewrite −10 as −6 + (−4). Then +6 and −6 make 0.

Remember: Decomposition explains the strategy instead of turning it into a rule to memorize.

04

Zero does not change a sum

Adding zero leaves a number unchanged. This is useful after an additive inverse pair has combined to make zero.

Remember: 0 + (−4) = −4.

05

Order can be changed when adding

The commutative property of addition says a + b = b + a. Rearranging addends can make additive inverses easier to spot, especially when adding three or more integers.

Remember: Only rearrange terms when the operation is addition.

COMMON MIX-UPS

“Adding a negative always gives a negative answer.”

Not always. In (+12) + (−5), the positive addend has the greater magnitude, so the sum is +7.

“Different signs means subtract in the order written.”

Compare magnitudes first. Subtract the smaller magnitude from the larger magnitude, then use the sign of the greater-magnitude addend.

“For two negative integers, subtract because the signs are negative.”

The signs are the same, so the movements combine. (−4) + (−6) = −10.

WATCH THE THINKING

Worked examples

Example 1 · Same positive signs

Find (+8) + (+5).

  1. The signs are the same.
  2. Add the magnitudes: 8 + 5 = 13.
  3. Keep the common positive sign.
Answer: +13

Example 2 · Same negative signs

Find (−9) + (−4).

  1. The signs are the same.
  2. Add the magnitudes: 9 + 4 = 13.
  3. Keep the common negative sign.
Answer: −13

Example 3 · Different signs

Find (+7) + (−12).

  1. The signs are different.
  2. Compare magnitudes: 12 > 7.
  3. Subtract: 12 − 7 = 5.
  4. The greater magnitude belongs to −12, so the sum is negative.
Answer: −5

Example 4 · Decompose to zero

Find (+6) + (−10) by decomposing.

  1. Rewrite −10 as (−6) + (−4).
  2. Group +6 with −6.
  3. (+6) + (−6) = 0.
  4. 0 + (−4) = −4.
Answer: −4

REAL-LIFE CHALLENGE

A class fundraiser records four changes: +$25, −$18, −$7, and +$10.

  1. Write one integer addition expression for the four changes.
  2. Rearrange the addends to make the calculation easier.
  3. Identify any pair or group that makes zero.
  4. Find the total change and explain your strategy.
Check the core ideas

One efficient arrangement is +25 + (−18) + (−7) + 10. Since −18 + (−7) = −25, +25 and −25 make 0, leaving +10. The total change is +$10.

LESSON SUMMARY

  • Same signs: add magnitudes and keep the common sign.
  • Different signs: subtract magnitudes and use the sign of the greater magnitude.
  • Decomposition can create an additive inverse and a zero pair.
  • Adding zero does not change a value.
  • The commutative property lets you rearrange addends.

IF YOU NEED SUPPORT

  • Predict the sign before calculating.
  • Use a two-column reminder: SAME SIGNS → add magnitudes; DIFFERENT SIGNS → compare magnitudes.
  • Return to integer chips whenever the symbolic strategy feels disconnected from meaning.

IF YOU WANT A CHALLENGE

  • Create three different sums with an answer of −6.
  • Find a four-integer sum that can be simplified by pairing two sets of additive inverses.
  • Explain why “different signs means subtract” is incomplete without mentioning magnitude.

PAT-STYLE THINKING

Which strategy is most efficient for (−18) + (+7)? A) Add 18 + 7 and keep the negative sign. B) Subtract 18 − 7 and use the negative sign. C) Subtract 18 − 7 and use the positive sign. D) Change both signs and add.

Show answer

B. The signs are different, so compare magnitudes. 18 − 7 = 11, and −18 has the greater magnitude, so the sum is −11.
