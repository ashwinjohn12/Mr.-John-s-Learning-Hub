START HERE

The big idea

You can simplify an algebraic expression by combining terms that represent the same kind of quantity.

Like terms have the same variable part. Their coefficients tell how many of that quantity you have. Combining 4x and 3x is like combining 4 identical x-tiles and 3 identical x-tiles to make 7x. Algebraic properties let us rearrange and regroup terms without changing the value of the expression.

1Spot the matchesWhich terms represent the same kind of quantity?
2Combine coefficientsAdd or subtract only within a like-term family.
3Check the valueSubstitute when useful to confirm equivalence.
Think about itWhy can 5 apples + 3 apples become 8 apples, while 5 apples + 3 oranges cannot become 8 of one thing?

LEARN

Build your understanding

01

Like terms represent the same kind of quantity

Terms such as 3x, −5x, and x are like terms because they all have the same variable part, x. Constant terms such as 4 and −9 are also like terms.

Remember: Match the variable part first.

02

Combine the coefficients

When you add or subtract like terms, add or subtract the numerical coefficients and keep the variable part unchanged. 4x + 3x = 7x.

Remember: The x does not become x² when you add x + x.

03

Unlike terms stay separate

5x and 2y are not like terms, so 5x + 2y is already simplified. The same is true for x and x² because their variable parts are different.

Remember: Do not invent a new variable combination just to make one term.

04

Rearrange to put like terms together

The commutative and associative properties let you reorder and regroup addition. For example, 7x − 8y + 5y − 2x can be rearranged to 7x − 2x − 8y + 5y.

Remember: Carry the sign with its term when you rearrange.

05

Distribute to remove parentheses

The distributive property multiplies every term inside the parentheses: 3(x + 2) = 3x + 6.

Remember: Distribute to every term, not just the first one.

Equivalent expressions and checking

Equivalent expressions have the same value

Two expressions can look different but still have the same value for every allowed value of the variable. Substitution is a useful way to check equivalence.

Remember: Simplifying changes the form, not the value.

VISUAL MODEL · LIKE TERMS

Same kind of tile → same kind of term

4x+3x→7x

The coefficient changes because you have more x-tiles. The variable part stays x.

COMMON MIX-UPS

“x + x = x².”

Addition counts how many x-terms there are: x + x = 2x. x² means x multiplied by x, which is a different operation.

“5x − 3y = 2xy.”

The terms are unlike, so they cannot be combined. The simplified expression stays 5x − 3y.

“I can drop the sign when I move a term.”

The sign belongs to the term. In 7x − 2x, the second term is −2x.

“3(x + 2) = 3x + 2.”

The 3 multiplies every term inside the parentheses, so the correct result is 3x + 6.

WATCH THE THINKING

Worked examples

Start with the two core examples. Open the next examples when you are ready to apply the same reasoning in a more complex situation.

Example 1 · Identify and combine like terms

Simplify 4x + 6x − 3.

  1. 4x and 6x are like terms because both use x.
  2. Add their coefficients: 4 + 6 = 10.
  3. The constant −3 is not like an x-term, so keep it separate.
Answer: 10x − 3

Example 2 · Two sets of like terms

Simplify 7x − 8y + 5y − 2x.

  1. Group the x-terms: 7x − 2x = 5x.
  2. Group the y-terms: −8y + 5y = −3y.
  3. The x- and y-terms are unlike, so stop.
Answer: 5x − 3y
Ready for more? Open Examples 3 and 4

Example 3 · Distribute and simplify

Simplify 2(x + 4) + 3x.

  1. Distribute 2: 2(x + 4) = 2x + 8.
  2. Write the expression as 2x + 8 + 3x.
  3. Combine like x-terms: 2x + 3x = 5x.
Answer: 5x + 8

Example 4 · Simplify, then evaluate

Simplify 4x + 8x − 9x, then evaluate when x = 2.

  1. Combine coefficients: 4 + 8 − 9 = 3.
  2. The simplified expression is 3x.
  3. Substitute x = 2: 3(2) = 6.
Answer: 3x; value = 6

LESSON SUMMARY

  • Like terms have the same variable part.
  • Combine coefficients when adding or subtracting like terms.
  • Unlike terms stay separate.
  • Algebraic properties let you rearrange, regroup, and distribute without changing value.
  • Equivalent expressions can be checked by substitution.
Need more help?
  • Circle or colour-code each family of like terms.
  • Use algebra tiles or letter cards before working symbolically.
  • Write subtraction as adding a negative term when signs are confusing.
  • Expand distribution with arrows to every term inside parentheses.
Want an extra challenge?
  • Create two different expressions that simplify to 7x − 3.
  • Find a value of x and verify that 3(x + 2) and 3x + 6 are equal.
  • Explain why x and x² cannot be like terms using an area model.

PAT-STYLE THINKING

A student simplifies 5x − 3y + 2x + y to 7x − 2y. Explain why this is valid.

Show a strong answer

The x-terms are like, so 5x + 2x = 7x. The y-terms are like, so −3y + y = −2y. The x- and y-terms remain separate because they are unlike terms.
