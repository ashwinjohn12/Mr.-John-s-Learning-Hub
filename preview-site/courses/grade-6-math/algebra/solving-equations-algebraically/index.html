LESSON 6.3 · GRADE 6 MATH

Solving Equations Step by Step

Turn the balance moves you already understand into efficient algebraic steps, then verify your solution.

Start with thisMake a prediction. You are not expected to know the answer yet.
A balance model is powerful, but would you want to draw dozens of tiles every time? Algebraic steps are a faster way to record the same balanced moves.

GET READY

Get ready for equations

BEFORE YOU START

  • Solve equations with balance or algebra-tile models.
  • Use inverse operations with positive and negative numbers.
  • Simplify expressions using like terms and distribution.

How will I know I understand it?
  • I can translate a model move into an algebraic step.
  • I can isolate a variable using inverse operations.
  • I can solve equations containing integers, decimals, or parentheses.
  • I can verify by substituting into the original equation.
  • I can write and solve an equation for a word problem.

START HERE

The big idea

Algebraic solving records the same balanced moves as a model, but more efficiently.

Inverse operations undo operations around the variable while preservation of equality keeps both sides balanced. Simplify first when needed, then isolate the variable. A solution is not complete until it can make the original left-hand side and right-hand side equal when substituted back into the equation.

1Simplify firstCombine or distribute when needed.
2Undo on both sidesUse inverse operations and preserve equality.
3VerifySubstitute into the original equation: LHS = RHS.
Think about itHow is adding 4 to both sides of x − 4 = −10 the symbolic version of adding four positive tiles to each side of a balance model?
📘

LEARN

Build your understanding

01

Inverse operations undo each other

Addition and subtraction are inverses; multiplication and division are inverses. Choose the operation that undoes what is attached to the variable.

Remember: Undo operations in a logical order.

02

Preserve equality symbolically

Write the same operation on both sides of the equation. This is the written version of keeping a balance level.

Remember: Every legal step creates an equivalent equation.

03

Simplify before solving

Combine like terms or distribute first when an equation is not yet in a useful form. 4x + 2x − 3 = 9 becomes 6x − 3 = 9.

Remember: Simplifying is preparation, not a separate solution.

04

Use LHS and RHS to verify

Substitute the solution into the original equation. Evaluate the Left Hand Side and Right Hand Side separately. A correct solution makes LHS = RHS.

Remember: Verify in the original equation.

05

Equations can model word problems

Choose a variable, translate the situation into an equation, solve, and interpret the result with units or context.

Remember: Define what the variable represents before writing the equation.

Other strategies can still work

Different strategies can lead to the same solution

Inspection, systematic trial, models, and algebraic inverse operations can all be valid. Algebraic solving becomes more efficient as equations become more complex.

Remember: Choose a strategy you can explain.

VISUAL MODEL · VERIFY

A solution must make both sides match

LHS2(4) + 3 = 11=RHS11

If the two evaluated sides are different, the proposed value is not a solution.

COMMON MIX-UPS

“Move the number across and change the sign.”

That shortcut hides the reason. Record the inverse operation on both sides so preservation of equality stays visible.

“Verification means repeat my solving steps.”

Verification substitutes the solution into the original equation and checks whether LHS equals RHS.

“I can distribute to only one term.”

A factor outside parentheses multiplies every term inside.

“Once I get x = something, I am finished.”

A quick verification can catch sign, distribution, or arithmetic errors.

WATCH THE THINKING

Worked examples

Start with the two core examples. Open the next examples when you are ready to apply the same reasoning in a more complex situation.

Example 1 · One operation with integers

Solve x − 4 = −10 and verify.

  1. Add 4 to both sides: x − 4 + 4 = −10 + 4.
  2. Simplify: x = −6.
  3. Verify: LHS = −6 − 4 = −10; RHS = −10.
Answer: x = −6; LHS = RHS

Example 2 · Two operations

Solve 4x + 2x − 3 = 9.

  1. Combine like terms: 6x − 3 = 9.
  2. Add 3 to both sides: 6x = 12.
  3. Divide both sides by 6: x = 2.
  4. Verify in the original expression.
Answer: x = 2
Ready for more? Open Examples 3 and 4

Example 3 · Parentheses

Solve 3(x + 2) = 9.

  1. Distribute: 3x + 6 = 9.
  2. Subtract 6 from both sides: 3x = 3.
  3. Divide by 3: x = 1.
  4. Verify: 3(1 + 2) = 9.
Answer: x = 1

Example 4 · Write an equation from words

Subtract 1.8 from a number. The result is 2.6.

  1. Let n be the unknown number.
  2. Write n − 1.8 = 2.6.
  3. Add 1.8 to both sides: n = 4.4.
  4. Verify: 4.4 − 1.8 = 2.6.
Answer: n = 4.4

OFF-SCREEN ACTIVITY

Model-to-Symbol Bridge

  1. Choose an equation such as 2x + 3 = 11.
  2. Model it with algebra tiles or a simple balance drawing.
  3. Write one symbolic equation step for every physical move.
  4. Solve until one x remains.
  5. Substitute your solution into the original equation and compare LHS and RHS.

Reflect: Which symbolic step matched each model move, and why did equality stay true?

LESSON SUMMARY

  • Algebraic steps record balanced model moves efficiently.
  • Inverse operations isolate the variable while preserving equality.
  • Simplify expressions before solving when needed.
  • A correct solution makes LHS = RHS in the original equation.
  • Equations can model and solve real situations.
Need more help?
  • Write the operation on both sides instead of using a “move it across” shortcut.
  • Use arrows for distribution before simplifying.
  • Return to a balance drawing if a symbolic step feels mysterious.
  • Verify every practice answer until the process feels automatic.
Want an extra challenge?
  • Solve one equation three ways: inspection, a model, and algebraically.
  • Create a two-step equation with solution x = −4 and verify it.
  • Write a perimeter problem that can be solved using a two-step equation.

PAT-STYLE THINKING

A student says x = 3 solves 2x + 5 = 12. Without re-solving the equation first, determine whether the student is correct and explain.

Show a strong answer

Substitute x = 3 into the original equation. LHS = 2(3) + 5 = 11, while RHS = 12. Since LHS ≠ RHS, x = 3 is not a solution.
