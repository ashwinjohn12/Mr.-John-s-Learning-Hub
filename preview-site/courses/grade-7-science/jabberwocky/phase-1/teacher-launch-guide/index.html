TEACHER GUIDE // PHASE 1

FIRST CONTACT
FIVE-MISSION LAUNCH

The teacher plan now matches exactly what students see: 5 missions · 18 core classes · 7 purposeful flex classes.

25 × 45 MIN18 CORE + 7 FLEX

BEFORE DAY 1

Set the system once.

Assign continents

Prepare student → continent → Team ID roster. Students should not manage backend metadata.

Choose submission mode

Team Records can be paper, digital or both. Keep routine JCEC metadata teacher-managed.

Use low-material defaults

Prefer shared stations, printed mats/cards, reused containers and ordinary classroom objects before buying dedicated kits.

Plan Mission 4 local case

Preselect the local issue and source cards before Week 3.

DAY 1
WEEK 1 · Mission 1 — Explore Your Environment

Welcome to Jabberwocky

Open →
BEFORE CLASS

Continent assignments + Team IDs ready; open Mission 1.

MATERIALS

Devices; continent roster; notebook/Pathfinder Log if used.

STUDENTS SEE / DO

Story launch → select assigned continent → view preliminary rating → short starting prediction → four core science ideas.

KEY SCIENCE

Biotic, abiotic, habitat, environmental conditions.

TEACHER EMPHASIS

The preliminary JCEC rating is a starting idea, not the answer.

COLLECT / ASSESS

Baseline prediction only; no major grade.

IF TIME RUNS OUT

Extended story discussion / continent sharing.

DAY 2
WEEK 1 · Mission 1 — Explore Your Environment

Earth Environmental Survey

Open →
BEFORE CLASS

Choose 3 safe microhabitats; check weather; stage one or a few shared field kits.

MATERIALS

Shared thermometer(s); string/markers; metre stick if available; clipboards/pencils; field sheet. Light/moisture tools are optional.

STUDENTS SEE / DO

Sample 3 areas and record temperature, light/moisture, evidence of life, surface/soil, human impact.

KEY SCIENCE

Biotic/abiotic evidence; observation vs inference; habitat variation.

TEACHER EMPHASIS

Record what you observe before explaining it. Rotate shared tools rather than requiring one set per team.

COLLECT / ASSESS

Field sheet — formative.

IF TIME RUNS OUT

Optional instruments / extra sites.

DAY 4
WEEK 1 · Mission 2 — Meet a Native Species

How Structures Help

Open →
BEFORE CLASS

Set up 2–3 shared resource stations before students enter; use desks, paper zones or reused shallow containers instead of dedicated trays.

MATERIALS

Shared spoons; tweezers; clothespins/tongs; chopsticks; one class timer; small classroom objects/counters; paper/desk resource zones; lab sheet.

STUDENTS SEE / DO

Learn structure/function/adaptation/needs → Survival Structures Lab.

KEY SCIENCE

A structure helps differently depending on job + environment.

TEACHER EMPHASIS

Same time, amount and rules; change the structure. Stations can rotate—no team needs a full duplicate kit.

COLLECT / ASSESS

Lab observations — formative.

IF TIME RUNS OUT

Extended oral defence.

DAY 10

Matter Moves Too

Open →
BEFORE CLASS

Prepare one simple water + carbon example.

MATERIALS

Ecosystem Map; pencils.

STUDENTS SEE / DO

DAY 11
WEEK 3 · Mission 4 — Watch the Ecosystem Change

Population Sampling

Open →
BEFORE CLASS

Place a 5×5 grid and one set of simple markers at each team; use beans, paper squares or existing counters.

MATERIALS

Printed 5×5 grid; ~30–50 beans/paper markers/classroom counters per team; randomizer if used; calculator optional.

STUDENTS SEE / DO

Estimate spread-out population → true count → cluster same population → estimate again.

KEY SCIENCE

Samples are useful, but distribution affects estimates.

TEACHER EMPHASIS

The same total population can produce different sample results.

COLLECT / ASSESS

Sampling record — formative.

IF TIME RUNS OUT

Repeated extra trials.

DAY 16
WEEK 4 · Mission 5 — Humans Have Arrived

The Incident

Open →
BEFORE CLASS

Print or draw one six-zone Stowaway Spread mat per team; no cups are required.

MATERIALS

6-zone paper mat; neutral counters/beans/paper markers; 4 contrasting stowaway markers; spoon/scoop if useful; incident record.

STUDENTS SEE / DO

Human-impact reveal → compare spread without vs with early checkpoint.

KEY SCIENCE

Human movement creates spread pathways; prevention can reduce spread.

TEACHER EMPHASIS

Introduced does not automatically mean invasive. Move markers between printed zones instead of building a container setup.

COLLECT / ASSESS

Simulation record — formative.

IF TIME RUNS OUT

Repeated simulation rounds.

DAY 17
WEEK 4 · Mission 5 — Humans Have Arrived

What Happens Next?

Open →
BEFORE CLASS

Prepare teacher-guided pollutant token model.

MATERIALS

16 producer paper tokens/cards; 4 consumer cards; 1 predator card; continent incident evidence.

STUDENTS SEE / DO

Check spread + harm evidence → short pollutant model → connect conservation risk.

KEY SCIENCE

Invasive requires spread + harm; persistent pollutants can biomagnify; local ≠ global extinction.

TEACHER EMPHASIS

X-17 is fictional; the ecological pattern is the learning target. Printed paper tokens work as well as physical counters.

COLLECT / ASSESS

No separate major submission.

IF TIME RUNS OUT

Extra clues / second pollutant scenario.

BUFFER IS A FEATURE

7 purposeful flex classes

These are not empty periods. They protect the core when weather, absences, school events or slower labs happen.

DAY 15Fieldwork / Mission 4 recovery buffer

Weather-rescheduled fieldwork, Mission 4 absences, sampling/succession reteach, or vocabulary review.

Protect the local environmental connection first.
DAY 20Recommendation Board completion / absence recovery

Finish major synthesis work or recover a missed Mission 5 investigation.

Use for essential completion before enrichment.
DAY 21Whole-unit science review

Retrieval, diagrams, evidence interpretation and recurring misconceptions.

Review science, not JCEC trivia.
DAY 22Short individual science check

Optional concise individual assessment when a clean individual mark is needed.

Focus on evidence interpretation, not story memorization.
DAY 23Reteach + targeted catch-up

Regroup by misconception; others finish missed reflections/artifacts.

Respond to actual assessment evidence.
DAY 24Optional gallery walk / continent briefing

Compare Recommendation Boards and why different continents produced different decisions.

Optional — cut before core learning.
DAY 25Final buffer / transition

Make-up, interruption recovery, final feedback or transition to Phase 2.

No new required Phase 1 content.
Flex priority: missed core investigation → absence recovery → unfinished synthesis → reteach → individual check → review/presentation → early transition.

RECOVERY PLAN

If real school life interrupts the unit

Lab runs long

Protect the scientific conclusion. Move Team Record completion to the next opening/flex period.

A class is lost

Use flex in order: Day 15 → 20 → 23 → 24 → 25.

Outdoor work cancelled

Use three contrasting indoor microhabitats and discuss the limitation.

Device failure

Use printed artifacts and project/read continent evidence.

Student misses a lab

Use team data + a short individual interpretation; do not recreate every physical lab alone.

Materials are limited

Use shared stations, printed zones/cards, reused classroom objects and teacher demonstrations before purchasing duplicate kits.

Students overwhelmed

Return to the mission's one essential question + one reasoning scaffold.
