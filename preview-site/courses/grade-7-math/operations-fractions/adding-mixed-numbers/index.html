START HERE

The big ideas

Mixed numbers can be combined by joining wholes and fractional parts or by using equivalent improper fractions.

Compose a new whole

Fractional parts totaling at least one can be exchanged for a whole.

Two valid strategies

Part-by-part and improper-fraction methods must agree.

📘

LEARN

Build your understanding

1. Model wholes and parts

Use same-sized wholes and equal fraction partitions. Estimate first and use the model to expose the error of using different-sized wholes.

Model: 2 1/3+1 1/6 has three wholes plus 3/6.

Common mix-up: using different-sized wholes

2. Part-by-part

Add whole parts, rename fractional parts, then compose if needed. Estimate first and use the model to expose the error of forgetting the composed whole.

Model: 1 3/4+2 2/3 gives 3+17/12=4 5/12.

Common mix-up: forgetting the composed whole

3. Improper fractions

Convert, add with a common denominator, then convert back. Estimate first and use the model to expose the error of mixing denominators and whole numbers.

Model: 7/4+8/3=21/12+32/12.

Common mix-up: mixing denominators and whole numbers

4. Estimate and choose form

Round to wholes or halves and report a form suited to context. Estimate first and use the model to expose the error of leaving an answer that contradicts the estimate.

Model: 2 7/8+1 1/6 is about 4.

Common mix-up: leaving an answer that contradicts the estimate

🧩

WATCH THE THINKING

Worked examples

No regrouping · Find 2 1/4+1 1/2.
  1. Add wholes: 3.
  2. Rename 1/2 as 2/4; fractions total 3/4.
  3. Combine to get 3 3/4.
  4. Check that 3 3/4 matches the benchmark, simplest form, and context.

Conclusion: 3 3/4

Compose a whole · Find 1 5/6+2 2/3.
  1. Rename 2/3 as 4/6.
  2. Fractions total 9/6=1 1/2.
  3. Wholes 1+2+1 give 4 1/2.
  4. Check that 4 1/2 matches the benchmark, simplest form, and context.

Conclusion: 4 1/2

Improper method · Find 2 1/5+1 3/4.
  1. Convert to 11/5 and 7/4.
  2. Use twentieths: 44/20+35/20=79/20.
  3. Convert to 3 19/20.
  4. Check that 3 19/20 matches the benchmark, simplest form, and context.

Conclusion: 3 19/20

Context · Walk 1 3/8 km then 2 1/4 km.
  1. Rename 1/4 as 2/8.
  2. Add wholes and fractions.
  3. State the distance unit.
  4. Check that 3 5/8 km matches the benchmark, simplest form, and context.

Conclusion: 3 5/8 km
