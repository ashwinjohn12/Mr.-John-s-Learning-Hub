Solving Equations Involving Integers

Use signed models, zero pairs, inverse operations, and substitution to solve equations.

START HERE

The big ideas

Positive and negative tiles make inverse operations and zero pairs visible while equality stays balanced.

Zero pairs change appearance, not value

A +1 and −1 pair has value zero and can be added without changing a side.

Direction matters

x−a and x+a require different inverse moves.

📘

LEARN

Build your understanding

1. Represent signs accurately

Positive and negative unit tiles must match the constant in the equation.

Model: x−3=−7 uses one x tile and three negative units on the left.

Common mix-up: using positive tiles for a negative constant

2. Add equal tiles

Add the same tiles to both sides to create removable zero pairs.

Model: Add three positive tiles to both sides of x−3=−7.

Common mix-up: adding tiles to only one side

3. Remove zero pairs

A positive and negative tile cancel because their sum is zero.

Model: −7+3 leaves −4 after three zero pairs are removed.

Common mix-up: removing two tiles with the same sign

4. Verify signed substitution

Keep brackets around negative substitutions.

Model: For x=−4, (−4)−3=−7.

Common mix-up: dropping the negative sign during substitution

🧩

WATCH THE THINKING

Worked examples

Negative solution · Solve x+5=−2.
  1. Add five negative tiles to both sides.
  2. Remove five zero pairs on the left.
  3. Seven negative tiles remain.

Conclusion: x=−7

Subtract a positive · Solve x−4=−9.
  1. Add four positive tiles to both sides.
  2. Remove four zero pairs.
  3. Five negative tiles remain.

Conclusion: x=−5

Subtract a negative · Solve x−(−3)=8.
  1. Subtracting −3 is adding 3.
  2. Subtract 3 from both sides.
  3. Check 5−(−3)=8.

Conclusion: x=5

Temperature context · A temperature rises 6°C to −1°C.
  1. Let t be the starting temperature.
  2. Write t+6=−1.
  3. Add −6 to both sides.

Conclusion: t=−7°C
