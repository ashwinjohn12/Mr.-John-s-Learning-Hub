START HERE

The big ideas

Graph tables of values and use the shape and coordinates to answer questions.

Each row becomes one point

Input is the horizontal coordinate; output is vertical.

Axes need meaning

Labels, units, and scale make a graph interpretable.

A graph shows the whole relation

Direction and steepness reveal how quantities change.

Points keep context

Discrete situations should not be joined as if all in-between inputs are possible.

Explain with evidenceRepresent the relationshipCalculate carefullyConclude in context
📘

LEARN

Build your understanding

Open each idea, study the model, and compare it with the common mix-up.

1Order coordinates

Write (input, output) or (x,y).

Model: Table row x=2,y=9 → (2,9).

Common mix-up: Do not reverse the coordinates.

2Design axes

Use equal intervals and include every value.

Model: x by 1, y by 5 may fit the data.

Common mix-up: A scale can skip numbers only with clear equal intervals.

3Plot precisely

Move along x, then up y.

Model: (3,11) means right 3, up 11.

Common mix-up: Do not treat grid squares as unlabeled units.

4Analyze

Read coordinates and compare change.

Model: A steeper rise means more output per input interval.

Common mix-up: Do not extend beyond the data without stating it is a prediction.

WATCH THE THINKING

Worked examples

TABLE TO GRAPHGraph y=3x+2 for x=0–3.
  1. Make pairs (0,2),(1,5),(2,8),(3,11).
  2. Label axes and choose a scale.
  3. Plot each pair.

Conclusion: Four points represent the relation.

READ A POINTWhat does (4,18) mean on a cost graph?
  1. First coordinate is quantity.
  2. Second coordinate is cost.

Conclusion: Four items cost $18.

COMPAREWhich plan grows faster?
  1. Compare equal horizontal intervals.
  2. The greater vertical rise has the greater rate.

Conclusion: Use slope-like change language, not a formal slope formula.

DISCRETE DATAShould points be connected for whole tickets?
  1. Partial tickets are not allowed.
  2. Only whole-number inputs are meaningful.

Conclusion: Leave the points discrete.
