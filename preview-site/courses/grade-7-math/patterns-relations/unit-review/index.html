TARGET YOUR REVIEW

Five concept stations

Open the station you selected. Retrieve the idea first, then compare your thinking with the example.

Lessons 1.1–1.2Divisibility and factor reasoning

Remember: Use the relevant ending for 2, 4, 5, 8, and 10; use the digit sum for 3 and 9; use both 2 and 3 for 6.

Example: For 1,368: digit sum 18 proves 3 and 9; evenness plus 3 proves 6; 368 proves 8, so 4 and 2 also work.

Lessons 1.3Expressions and substitution

Remember: An expression names a value. Keep order-sensitive language and use parentheses when an entire result is multiplied.

Example: “Subtract 3, then double” is 2(n−3). At n=8, its value is 10.

Lessons 1.4–1.5Patterns, relations, and tables

Remember: The constant change becomes the coefficient. Use a known input-output pair to find the fixed part, then test every row.

Example: Outputs 6, 10, 14 change by 4. For inputs 1, 2, 3, the rule is y=4x+2.

Lessons 1.6Graphing relations

Remember: Write input first, choose equal scale intervals, label both axes, and connect points only when the context permits every in-between value.

Example: The row x=3, y=11 becomes the point (3,11).

Lessons 1.7–1.8Equations and equality

Remember: An equation claims equal values. Apply the same operation to both sides, then substitute the solution into the original equation.

Example: x+5=13 → subtract 5 from both sides → x=8; check 8+5=13.

COMMON-MISTAKE REPAIR

Repair Shop

Choose the repair that fixes the reasoning—not only the final answer.

“A digit sum of 12 proves divisibility by 9.”

Repair: 12 proves divisibility by 3, not 9. A digit sum must itself be a multiple of 9.

Review Lesson 1.2 →
“A number ending in 8 must be divisible by 8.”

Repair: An even final digit proves divisibility by 2. For 8, test the entire final three-digit number.

Review Lesson 1.1 →
“Three less than twice n is 2(n−3).”

Repair: “Twice n, then subtract 3” is 2n−3. The parentheses would double both n and −3.

Review Lesson 1.3 →
“The +4 change means the rule is n+4.”

Repair: A constant change of 4 gives coefficient 4. Use one pair to find the fixed part.

Review Lesson 1.4 →
“A rule works because it matches one table row.”

Repair: Different rules can share one pair. Test the proposed rule against every known row.

Review Lesson 1.5 →
“Table row x=3, y=11 becomes (11,3).”

Repair: Ordered pairs use input first: (3,11).

Review Lesson 1.6 →
“n+8 is the equation for a number plus 8 equals 25.”

Repair: n+8 is only an expression. The complete equality claim is n+8=25.

Review Lesson 1.7 →
“To solve 4x=28, subtract 4.”

Repair: Division undoes multiplication. Divide both sides by 4, then verify x=7.

Review Lesson 1.8 →
“0÷0=0 because zero shared equally is zero.”

Repair: Every value q makes 0×q=0, so division cannot select one unique quotient. That makes 0÷0 undefined.

Review Lesson 1.2 →
“The point is (3,12), so each grid square must equal 1.”

Repair: Read the numbered scale. Equal grid intervals may represent 1, 2, 5, or another consistent amount.
