START HERE

The big ideas

Divisibility rules are place-value patterns, not magic tricks.

Divisible means no remainder

Equal groups use every item, so the quotient is a whole number.

Only an ending may matter

Use one digit for 2, 5, 10; two for 4; three for 8.

Some rules are nested

8 → 4 → 2, while 10 → 5 and 2.

Explain with precisionRule → which ending?Evidence → why does it work?Conclusion → what is true?

PLACE-VALUE PROOF

Why can you ignore the front?

46,728 = 46,000 + 728. Each thousand is divisible by 8 because 1,000 = 8 × 125. Only 728 can create a remainder.

COMMON MIX-UPS

“It ends in 8, so it must be divisible by 8.”

No. For 8, test the last three digits. For example, 138 ends in 8 but is not divisible by 8.

“Every even number is divisible by 4.”

Even proves divisibility by 2. The number 14 is even but is not a multiple of 4.

WATCH THE THINKING

Worked examples

EXAMPLE 1 · TEST ALL FIVE

Which rules work for 46,728?

  1. 2: 8 is even → yes.
  2. 4: 28 = 4 × 7 → yes.
  3. 8: 728 = 8 × 91 → yes.
  4. 5 and 10: it ends in neither 0 nor 5 → no.

Conclusion: divisible by 2, 4, and 8.

  2. So 732 and 736 are divisible by 4.
  3. For 8, test each whole three-digit number: only 736 = 8 × 92.

EXAMPLE 4 · REPAIR

Ari uses 64 to test 7,642 for divisibility by 4.

The relevant last two digits are 42, not 64. Since 42 is not divisible by 4, neither is 7,642.
