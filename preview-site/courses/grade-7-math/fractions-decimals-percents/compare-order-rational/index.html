LEARN

Build your understanding

1. Compare place values

Append zeros and compare from left to right. Use the model 0.830>0.803. to keep the quantities and place values visible. Estimate or compare with a benchmark before accepting the result; this also exposes the common error of counting decimal digits.

Model: 0.830>0.803.

Common mix-up: Counting decimal digits.

2. Convert strategically

Change only the form that clarifies the comparison. Use the model 5/8=0.625>0.61. to keep the quantities and place values visible. Estimate or compare with a benchmark before accepting the result; this also exposes the common error of rounding too early.

Model: 5/8=0.625>0.61.

Common mix-up: Rounding too early.

3. Use benchmarks

Compare the numerator with half or all of the denominator. Use the model 7/15<1/2. to keep the quantities and place values visible. Estimate or compare with a benchmark before accepting the result; this also exposes the common error of comparing numerators alone.

Model: 7/15<1/2.

Common mix-up: Comparing numerators alone.

4. Order on a line

Least lies left; greatest lies right. Use the model 0.45<1/2<0.7<1. to keep the quantities and place values visible. Estimate or compare with a benchmark before accepting the result; this also exposes the common error of omitting whole numbers.

Model: 0.45<1/2<0.7<1.

Common mix-up: Omitting whole numbers.

WATCH THE THINKING

Worked examples

Place value · Compare 0.908 and 0.89.
  1. Write 0.890.
  2. Compare thousandths.
  3. Check that 0.908>0.890 has a reasonable size and keeps the required unit or representation.

Conclusion: 0.908>0.890

Convert · Compare 3/5 and 0.62.
  1. 3/5=0.60.
  2. Compare hundredths.
  3. Check that 3/5<0.62 has a reasonable size and keeps the required unit or representation.

Conclusion: 3/5<0.62

Benchmark · Compare 8/15 and 1/2.
  1. Half of 15 is 7.5.
  2. 8 is greater than 7.5.
  3. Check that 8/15>1/2 has a reasonable size and keeps the required unit or representation.

Conclusion: 8/15>1/2

Mixed order · Order 0.48,3/4,0.7,1.
  1. Convert 3/4 to 0.75.
  2. Place values left to right.
  3. Check that 0.48<0.7<3/4<1 has a reasonable size and keeps the required unit or representation.

Conclusion: 0.48<0.7<3/4<1
