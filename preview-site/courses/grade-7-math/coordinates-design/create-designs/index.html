START HERE

Four ideas make a design reproducible

A coordinate design is more than a picture. It is a set of exact vertex locations plus instructions for how to connect them.

Vertices are exact addresses

Each corner can be labelled with a capital letter and an integral ordered pair, such as A(−4, 6).

Connection order matters

The same points can make a different figure when they are connected in a different sequence.

Closing is an instruction

To make a closed figure, connect the final vertex back to the first. Do not assume a design closes unless the instructions say so.

A good recipe can be tested

If another person can rebuild your design using only its coordinates and connection order, your mathematical communication is precise.

📘

LEARN

Build your design routine

1. Find and label the vertices

A vertex is a point where two sides meet; more than one are vertices. Label them A, B, C, … so each point has an unambiguous name.

Common mix-up: A point along the middle of a straight side is not automatically a vertex. Look for places where sides begin, end, or change direction.

2. Record every vertex as (x, y)

Read horizontally first to find x, then vertically to find y. Write the label with the ordered pair: C(5, −3). Points on an axis still work: (0, 6) or (−7, 0).

Quality check: Point to the plotted location, say “x, then y,” and verify both signs.
3. Reproduce a design from instructions
  1. Read the axes and scale.
  2. Plot and label every ordered pair.
  3. Follow the stated connection order exactly.
  4. Connect the final vertex back to the first only when instructed.
  5. Compare the completed design with the coordinate list, not with a guess about what it “should” look like.
4. Create a design that someone else can rebuild

Choose integral-coordinate grid intersections for your vertices. Record each coordinate as you create it, in the same order you intend the segments to be drawn. Keep labels unique.

Common mix-up: Writing coordinates after drawing from memory can change the order. Record the mathematical recipe while you build.

5. Test the communication, not just the picture

Hide the original design and rebuild it using only your written instructions. If the new copy differs, diagnose whether the problem is a coordinate, a sign, a vertex label, the connection order, or a missing closing segment.

Example 4 · Write reproducible instructions

A design uses P(−4, 1), Q(0, 6), R(5, 2), S(3, −5), T(−3, −4).

Complete recipe

Scale 1. Plot and label P, Q, R, S, T. Connect P → Q → R → S → T → P.

A classmate does not need to see the picture. The point addresses and connection order are enough to rebuild it.

    After you reproduce it

    1. Which vertices lie in different quadrants?
    2. Which segment crosses an axis?
    3. Compare the alternate connection order. Which coordinates changed?
