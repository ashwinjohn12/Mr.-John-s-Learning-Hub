START HERE

The big ideas

A point on a Cartesian plane has an exact mathematical address: (x, y).

Two number lines make one plane

The horizontal x-axis and vertical y-axis cross at the origin and divide the plane into four quadrants.

Order matters

Read x first, then y. The points (3, −2) and (−2, 3) are not the same location.

Signs tell direction

Positive x is right, negative x is left. Positive y is up, negative y is down.

Read the scale

A square is not always one unit. Axes may count by 1s, 2s, 5s, 10s, or another stated scale.

📘

LEARN

Build your understanding

1. Build the Cartesian plane

The x-axis runs horizontally and the y-axis runs vertically. Their intersection is the origin, (0, 0). The axes are boundaries that divide the plane into four quadrants.

Memory cue: x is across; y is up/down.
2. Number the four quadrants

Start in the upper-right and move counterclockwise: Quadrant I, II, III, IV.

I(+,+)
II(−,+)
III(−,−)
IV(+,−)

Common mix-up: Quadrants are not numbered left-to-right. They go counterclockwise beginning in the upper-right.

3. Read an ordered pair: x first, y second

For (−3, 5), begin at the origin. Move 3 units left because x = −3. Then move 5 units up because y = 5. Plot the point where you finish.

Common mix-up: Swapping x and y changes the point. Always move horizontally first.

4. Points on axes are not in quadrants

A point written (x, 0) lies on the x-axis. A point written (0, y) lies on the y-axis. The point (0, 0) is the origin. These points sit on quadrant boundaries, so they are not inside any quadrant.

5. Read the axis scale before counting

First inspect the labels on the axis. If each grid interval represents 5, three squares right means x = 15, not x = 3. Grade 7 questions may use scales of 1, 2, 5, or 10.

Common mix-up: Counting squares correctly but ignoring the scale still gives the wrong coordinate.

WATCH THE THINKING

Worked examples

Example 1 · Read a point

COORDINATE MODEL

Example point A

x first: move left or right. y second: move down or up.

  1. Start at the origin.
  2. A is 6 units left, so x = −6.
  3. A is 4 units up, so y = 4.
  4. A(−6, 4) is in Quadrant II.

Example 2 · Plot a point

Plot B(5, −3).

  1. Start at (0, 0).
  2. x = 5 → move 5 units right.
  3. y = −3 → move 3 units down.
  4. Mark B in Quadrant IV.

Example 3 · A point on an axis

For C(0, −7), x = 0 means do not move left or right. Move 7 down. C lies on the y-axis, not in Quadrant III or IV.

Example 4 · Scale of 5

Point D is 4 squares left and 3 squares up on a grid where each square represents 5.

  1. x = −4 × 5 = −20.
  2. y = 3 × 5 = 15.
  3. So D(−20, 15).
