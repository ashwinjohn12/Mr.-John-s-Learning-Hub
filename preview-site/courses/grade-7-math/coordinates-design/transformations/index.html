🌎

START HERE

Three motions, one coordinate language

A transformation changes a figure's position or orientation while keeping corresponding vertices connected to the same figure.

Translation = slide

Every vertex moves the same amount in the same directions.

Reflection = mirror

Each image point lands on the opposite side of a line of reflection at the same perpendicular distance.

Rotation = turn

Every vertex turns through the same angle around one fixed centre of rotation.

Coordinates verify the image

Prime-labelled vertices such as A′, B′, C′ let us match each image point to its original point.

📘

LEARN

How to perform and describe transformations

1. Original figure and image

Start with the original vertices A, B, C. After one transformation, the matching image vertices are labelled A′, B′, C′, read “A prime,” “B prime,” and “C prime.” The labels show correspondence: A ↔ A′, B ↔ B′, C ↔ C′.

Do not relabel randomly: A′ must be the image of A.

2. Translation: every point follows the same slide

A translation is described by how far the whole figure slides left/right and up/down. Apply that exact slide to every vertex, plot the prime points, then reconnect them in the original vertex order.

Common error: moving different vertices different amounts changes the figure instead of translating it.

3. Reflection: use the mirror line

For each original vertex, measure the shortest path to the line of reflection. That path is perpendicular to the line. Plot the image vertex the same perpendicular distance on the opposite side, then reconnect corresponding image vertices.

Reflection check: original point → mirror line → image point forms a perpendicular path with equal distance on both sides.

4. Rotation: centre + angle + direction

A rotation turns the figure around a fixed centre of rotation. A complete description includes the centre, the angle, and whether the turn is clockwise or counterclockwise. Common quarter-turn angles are 90°, 180°, and 270°.

Common error: assuming every rotation is about the origin. Use the centre that is actually given.

5. Verify the image with coordinates

After transforming, list the coordinates of A′, B′, C′ and compare each image vertex with the transformation description. The whole shape should still have the same side lengths and angle sizes.

6. Successive transformations

A figure can undergo more than one transformation. Finish the first image accurately before using it as the starting figure for the next transformation. Keep the transformation descriptions separate and preserve vertex correspondence throughout.

Scope note: today we track the image coordinates and transformation sequence. Lesson 1.4 will analyze horizontal and vertical changes between positions.

WATCH THE THINKING

Worked examples

Example 1 · Translation

Start with A(−4, 1), B(−1, 4), C(2, 1). Translate 5 units right and 3 units down.

COORDINATE MODEL

Translation image vertices

x first: move left or right. y second: move down or up.

Image coordinates: A′(1, −2), B′(4, 1), C′(7, −2). Each vertex followed the same slide.

Example 2 · Reflection

Reflect P(−5, 3), Q(−2, 6), R(−1, 2) across the y-axis.

COORDINATE MODEL

Reflection image across the y-axis

x first: move left or right. y second: move down or up.

Each image point is the same perpendicular distance from the y-axis on the opposite side.

Example 3 · Rotation

Rotate triangle JKL with J(2, 1), K(5, 1), L(5, 4) 90° counterclockwise about (0, 0).

COORDINATE MODEL

Rotation image about the origin

x first: move left or right. y second: move down or up.

The centre, angle, and direction fully describe the turn.

Example 4 · Identify the transformation

If every original vertex has an image directly across the line x = 2 at the same perpendicular distance, the transformation is a reflection in x = 2. Coordinates provide the evidence; the picture alone is not enough.

Investigate deliberately

  1. Try the same triangle under all three transformation types.
  2. For reflections, change the mirror line from vertical to horizontal.
  3. For rotations, compare 90°, 180°, and 270° and move the centre away from the origin.
  4. For every image, identify which vertex corresponds to A, B, and C.

Key conclusion: the transformation description must explain how the whole figure moves, not just where one point ends.
