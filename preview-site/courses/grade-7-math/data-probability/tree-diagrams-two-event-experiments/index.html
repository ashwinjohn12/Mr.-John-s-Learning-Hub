START HERE

The big ideas

Two-event probability is trustworthy only when the sample space is complete and independence is justified.

Independence preserves the second event

The first result does not change the probability model for the second.

Theory and experiment differ

Theory comes from the model; experimental probability comes from observed relative frequency.

📘

LEARN

Build your understanding

1. Independent events

Ask whether first result changes second-event probabilities.

Representation connection: Repeat identical second-event branches after every first outcome.

Common mix-up: Calling events independent just because they occur at different times.

2. Build the sample space

Include every ordered pair exactly once; a×b pairs for a and b outcomes.

Representation connection: Rows × columns or complete tree branches.

Common mix-up: Listing only favourable outcomes.

3. Theoretical probability

Count favourable ordered pairs over all equally likely ordered pairs.

Representation connection: Highlight favourable cells in complete table.

Common mix-up: Adding outcome counts instead of multiplying.

4. Experimental versus theoretical

Compare observed favourable/trials to theory; finite experiments vary.

Representation connection: Place theory and experimental relative frequency side by side.

Common mix-up: Demanding exact equality in a small sample.

🧩

WATCH THE THINKING

Worked examples

Example 1 · Coin then die independent?
  1. Coin does not change die probabilities.

Conclusion: Yes.

Example 2 · How many outcomes?
  1. 2×6=12.

Conclusion: 12 ordered pairs.

Example 3 · P(head and even)?
  1. H2,H4,H6: 3 of 12.
  2. 3/12=25%.

Conclusion: 25%.

Example 4 · 28 wins/100 vs theory 25%?
  1. Experimental 28%.
  2. Difference 3 percentage points; variation expected.

Conclusion: Close, not exact.
