START HERE

The big ideas

I will represent an integer with a context, chips, and a number line, and explain why different-looking models can have the same value.

Signs need a reference

A sign can describe location or direction. Name what counts as zero.

Opposites mirror across zero

Opposites have equal magnitude and different directions.

Zero pairs preserve value

One positive and one negative chip total zero, so they change appearance but not value.

Models can be equivalent

Any number of zero pairs may be added without changing the integer.

LEARN

Build your understanding

Open one idea at a time. Compare the model with the common mix-up.

1Position and change

A position tells where something is relative to zero. A change tells how far and in which direction it moved.

Model: -4°C is a position. A fall of 4°C is a change of -4°C.

Common mix-up: Treating a change as the final position.

2Opposites and zero

Opposites are equally far from zero in opposite directions. Zero is its own opposite and is neither positive nor negative.

Model: +6 and -6 are both 6 units from 0.

Common mix-up: Calling zero positive because it has no minus sign.

3Read chip value

Pair one positive with one negative. Each pair totals zero; count the sign and number that remain.

Model: 4P/9N has four zero pairs and 5N left, so it is -5.

Common mix-up: Counting 13 chips instead of their signed value.

4Equivalent chip models

Adding complete zero pairs creates a different-looking model with the same value.

Model: 3N, 5N/2P, and 8N/5P all model -3.

Common mix-up: Believing a model with more chips has a greater value.

5Horizontal and vertical lines

Right and up are positive directions; left and down are negative. Points show positions and arrows can show changes.

Model: -7 is seven intervals left or below zero.

Common mix-up: Counting tick marks instead of intervals.

WATCH THE THINKING

Worked examples

ContextAn elevator is 5 floors below ground.
  1. Name ground as the reference 0.
  2. Below gives a negative direction.
  3. Write -5.

Conclusion: The elevator position is -5 floors.

Chip modelRead 4P and 9N.
  1. Circle four unlike pairs.
  2. Each pair totals zero.
  3. Five negative chips remain.

Conclusion: The value is -5.

Equivalent modelsBuild three models for +4.
  1. Start with 4P/0N.
  2. Add two pairs: 6P/2N.
  3. Add three more pairs: 9P/5N.

Conclusion: All three have P-N=4.

Fixed countWhat values can 9 chips make?
  1. Begin with 9N: -9.
  2. Replace one N with one P; value changes by 2.
  3. Continue through +9.

Conclusion: -9,-7,-5,-3,-1,+1,+3,+5,+7,+9.
