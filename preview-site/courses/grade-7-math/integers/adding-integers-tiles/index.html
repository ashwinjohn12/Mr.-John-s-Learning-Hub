START HERE

The big ideas

I will add integers by combining chip models, removing zero pairs, and using what remains to explain the sign and value of the sum.

Addition combines

Build both addends before cancelling.

Same signs join

No unlike pairs form; magnitudes combine and the common sign remains.

Different signs cancel

The greater magnitude determines which sign remains.

Opposites total zero

Equal positive and negative quantities cancel completely.

LEARN

Build your understanding

Open one idea at a time. Compare the model with the common mix-up.

1Translate signed changes

Gains, rises, credits, right, and up are positive; losses, falls, debits, left, and down are negative.

Model: Gain 7 then lose 11 becomes (+7)+(-11).

Common mix-up: Treating the second change as subtraction just because it is negative.

2Build, combine, cancel, count

Keep two labelled sets until combining. Then pair unlike chips and count what remains.

Model: (+8)+(-5) leaves 3P after five pairs cancel.

Common mix-up: Cancelling same-sign chips.

3Predict the sign

With unlike signs, compare magnitudes. Equal magnitudes give zero.

Model: In (-9)+(+4), magnitude 9 is greater, so the sum is negative.

Common mix-up: Using the sign of the first addend automatically.

4Explain the remainder

Name how many pairs cancel and which signed chips remain.

Model: (+5)+(-8): five pairs cancel; 3N remain; sum -3.

Common mix-up: Saying only “the bigger number wins.”

5Efficient additions

Adding zero preserves value. Reordering can reveal opposite pairs in a longer sum.

Model: (-8)+(+3)+(+8) groups the opposites first, leaving +3.

Common mix-up: Assuming addition order changes the sum.

WATCH THE THINKING

Worked examples

Same positive signs(+4)+(+7)
  1. Build 4P and 7P.
  2. Combine to 11P.
  3. No zero pairs form.

Conclusion: +11

Same negative signs(-6)+(-3)
  1. Build 6N and 3N.
  2. Combine to 9N.

Conclusion: -9

Unlike signs(+8)+(-5)
  1. Combine 8P and 5N.
  2. Cancel five pairs.
  3. Count 3P.

Conclusion: +3

Opposites(+12)+(-12)
  1. Combine equal positive and negative counts.
  2. Cancel twelve pairs.

Conclusion: 0

ContextGain 7 points, then lose 11.
  1. Write (+7)+(-11).
  2. Cancel seven pairs.
  3. Four negative points remain.

Conclusion: Overall change -4 points.
