START HERE

The big ideas

I will subtract integers by building the first value, removing the second value, and adding zero pairs when the needed chips are missing.

Build only the first value

The subtrahend names what must be removed.

Removal has direction

Removing positive lowers value; removing negative raises value.

Add complete zero pairs

They supply missing chip types without changing the start.

Order matters

Reversing a subtraction generally reverses the sign of the difference.

LEARN

Build your understanding

Open one idea at a time. Compare the model with the common mix-up.

1Name each role

In a-b, a is the minuend or start, b is the subtrahend or amount removed, and the result is the difference.

Model: (+8)-(-3): build +8 and remove 3N.

Common mix-up: Building both integers and combining as in addition.

2Ready removal

If the starting model already contains enough of the needed chip type, remove immediately.

Model: (-7)-(-4): remove 4N and leave 3N.

Common mix-up: Adding pairs when they are not needed.

3Add zero pairs

If needed chips are missing, add the exact shortage as complete positive-negative pairs.

Model: (+3)-(-5): add 5P/5N, remove 5N, leave 8P.

Common mix-up: Adding unmatched negative chips.

4Negative start, positive removal

Supply missing positive chips with pairs, then remove them.

Model: (-4)-(+6): add six pairs, remove 6P, leave 10N.

Common mix-up: Changing the first integer’s sign.

5Equivalent starting models

A displayed model may already contain some needed chips; add only the shortage.

Model: 2P/5N represents -3 and already contains two P.

Common mix-up: Ignoring chips already present.

WATCH THE THINKING

Worked examples

Ready positive removal(+9)-(+4)
  1. Build 9P.
  2. Remove 4P.
  3. Count 5P.

Conclusion: +5

Ready negative removal(-8)-(-3)
  1. Build 8N.
  2. Remove 3N.

Conclusion: -5

Need positive chips(+2)-(+7)
  1. Add five zero pairs.
  2. Remove 7P.
  3. Five N remain.

Conclusion: -5

Remove negatives(+4)-(-6)
  1. Add six zero pairs.
  2. Remove 6N.
  3. Ten P remain.

Conclusion: +10

Negative start(-5)-(+3)
  1. Add three pairs.
  2. Remove 3P.
  3. Eight N remain.

Conclusion: -8
