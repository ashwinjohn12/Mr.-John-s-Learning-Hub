First Code

First, make something move. Do not add score, target logic, or controller actions yet.

04

YOUR GAME

Build It — Timing Target Game

Turn the guided example into a game another student can play. Keep the core game simple, then make at least one meaningful choice of your own.

GOAL

Press at the right moment to score.

CONTROL

Fire 1 or A — use your assigned path.

RULE

IF the moving object is at/in the target → score. Otherwise → end.

☐ One visible moving game object☐ Movement repeats continuously☐ One physical controller action☐ One clear target/success rule☐ One IF decision☐ Success increases score☐ Failure ends the round/game☐ Game works on physical hardware☐ Player can understand the game quickly☐ At least one meaningful personalization☐ Another student playtested it☐ We improved one thing and retested

Make one meaningful choice

Speed

Make the timing easier or harder.

Target

Change where or when success happens.

Score

Change how many points success earns.

Theme

Change the look or message without changing the core rule.

✓ Build It is ready when: another student can understand the goal, use the controller, experience success and failure, and you can explain one improvement you made after testing.

Playtest and improve

PLAYPlayer tries once without creator help.→NOTICEWas the goal clear? Was timing fair? Did score/failure work?→CHANGEImprove one thing based on what happened.→RETESTTry again and see if the change helped.
STUCK? TRY 4

1. CHECK — blocks, values, order, and nesting. 2. SIMULATE the newest version. 3. DOWNLOAD the newest version. 4. PARTNER — briefly explain expected vs actual to a nearby student. Still stuck? Ask for help and say what you already tried.

05

OPTIONAL CHALLENGE

Level It Up

Only after every Build It requirement works. Choose one while you wait for your checkpoint.

Speed Tuner

Change movement speed and decide which version is most playable.

Random Target

Use randomness to change the target position/location between rounds.

Two Controls

Add one second meaningful controller action.

Win Goal

Add a simple score target or another clear ending rule.

Mission 3 limit: do not add advanced Arcade scenes, enemies, tilemaps, or multiple levels yet.

When every Build It box is checked and your improvement is retested, add your name to the Ready-for-Check queue. Keep Leveling Up until you are called.

06

SHOW WHAT YOU KNOW

Checkpoint

Bring your controller and open your code when you are called. The checkpoint is individual: you demonstrate, explain, change, and test your own game.

Check 1 — Play / Identify

Demonstrate the game. Point to the physical action button and the code event that responds to it.

Check 2 — Explain the System

Explain what keeps the object moving, what the IF rule checks, what success does to the score, and what causes the game to end.

Check 3 — Change It

Change target position/location, movement speed, scoring amount/behaviour, or the action button. Predict first, then test.
