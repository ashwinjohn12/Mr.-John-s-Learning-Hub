01

GET READY

Set Up

Grab your tools, find the four parts you will use today, and make sure your station is ready.

☐ Computer☐ micro:bit☐ USB data cable☐ Mission page open

Find these four parts: Button A · Button B · 5×5 LED display · USB port.

Button A + Button B

These are inputs. You press them to give information to the program.

LED display

This is an output. Your program can make it show images, numbers, and words.

If you are working with a partner

DRIVERControls the computer and connects the micro:bit.NAVIGATORReads the next step, predicts results, and checks requirements.

Start with these roles. Switch at Stage 3. Both partners must be able to explain the code.

Maker rules

☐ Handle equipment carefully☐ Keep food and drinks away☐ Never force a connection☐ Return everything when finished
02

FIRST SUCCESS

First Code

Create a tiny program, test it on screen, then send it to the real micro:bit.

1 — Open MakeCode

Open MakeCode for micro:bit ↗. Choose New Project. Name it FirstName_L1_M1.

2 — Make your first program

Put show string inside on start. Type your initials.

3 — Test the simulator

Your initials should scroll across the virtual micro:bit on screen.

4 — Run it for real

Connect the micro:bit with USB. Click Download and send the newest program to the device.

✓ Success looks like this: your initials scroll across the real micro:bit.

If it does not work: check the cable, test the simulator, then download the newest version again.

Mini Check: point to the output. The LED display is the output because it shows the result of the program.

03

INPUT → CODE → OUTPUT

Make It React

WORKING WITH A PARTNER? SWITCH ROLES NOW.

INPUT: ButtonCODE: EventOUTPUT: LED display
Challenge A — Button A

Add on button A pressed. Put show icon inside it. Pick any icon.

Challenge B — Button B

Add on button B pressed. Make it show something different.

Challenge C — Sequence

Make one button run at least three instructions. Example: image → pause → image.

What is a sequence?

A sequence is a set of instructions happening in order.

✓ Before moving on: test A, test B, and run the program on the physical micro:bit.

If an animation changes too fast, add a pause between images.

04

YOUR CREATION

Build It — Interactive Badge

Create a digital badge that tells us something about you. It must react differently to Button A and Button B.

☐ Button A works☐ Button B works☐ The responses are different☐ One response uses a sequence☐ It runs on the real micro:bit☐ You changed it to make it yours

Need an idea?

Idea 1

A = favourite activity · B = initials + animation.

Idea 2

A = happy face · B = favourite number.

STUCK? TRY 4

1. CHECK your blocks. 2. SIMULATE the newest code. 3. DOWNLOAD the newest version. 4. PARTNER — explain what should happen. Still stuck? Ask for help and say what you already tried.

05

OPTIONAL CHALLENGE

Level It Up

Only after Build It works. Choose one while you wait for your checkpoint.

Shake It

Make shaking the micro:bit trigger an output.

A + B

Add a third response when A and B are pressed together.

Animator

Create an animation with at least five frames.

Explorer

Find another MakeCode input and make it work.

When every Build It box is checked, add your name or pair to the Ready-for-Check queue. Keep Leveling Up until you are called.

06

SHOW WHAT YOU KNOW

Checkpoint

Bring your micro:bit and open your code when you are called. Each student completes the checkpoint individually.

Check 1 — Make It Work

Press A or B. Identify the input and the output.

Check 2 — Explain It

Point to one event. Explain what makes that code run.

Check 3 — Change It

Make one small change chosen by the teacher. Test the new version.

After Your Check

PASS = Mission Complete. NOT YET = fix one skill and retry.
