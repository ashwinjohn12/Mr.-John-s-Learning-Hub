DO NOT SWAP THE PORTS: the 3-wire Light Sensor goes to Sensor Port 1. The 2-wire LED goes to LED Port 1.

CONNECT WITH POWER OFF
  1. Power OFF first.
  2. Insert/check the micro:bit. Never force it.
  3. Light Sensor → Sensor Port 1: yellow → S · red → + · black → –.
  4. LED → LED Port 1: colored wire → + · black wire → –.
  5. Do a 3-wire / 2-wire check before powering on.
  6. Turn Hummingbird power ON only when you are ready to test.
  7. Turn power OFF again before removing or reconnecting any part.

STUCK? TRY 4

1 CHECK — power → 3-wire sensor / 2-wire LED → port numbers → read current value → compare to threshold → IF/ELSE → newest code. 2 SIMULATE — inspect the logic structure. 3 DOWNLOAD — send the newest program. 4 PARTNER — explain current value, threshold, expected result, and actual result to a nearby student.

Still stuck? Ask for help and say what you already tried.

LED NEVER CHANGES? DO NOT GUESS FIRST.
  1. Read the current sensor value.
  2. Compare it to your threshold.
  3. Cover/uncover the sensor and check whether the value crosses the threshold.
  4. If the value crosses but the LED does not change, inspect the IF/ELSE and LED block.

If hardware still appears faulty after TRY 4, report the HB station number instead of moving components between stations.

05

OPTIONAL CHALLENGE

Level It Up

Only after Reactive Signal works. Choose one while you wait for your checkpoint.

⭐ Tune the Threshold

Change the threshold deliberately. Decide whether the reaction becomes more reliable. TEST → OBSERVE → ADJUST

⭐ Two Brightness Levels

Use two different non-zero LED brightness values instead of only ON and OFF.

⭐⭐ Servo Reaction

Reuse the Mission 4 position servo as a second output: dark → one angle · bright → another angle. This is optional and not part of the checkpoint.

⭐⭐ Three Light Zones

Use two thresholds to create three LED response zones. This may require another IF structure.

MISSION 5 LIMIT: no second sensor, obstacle navigation, wheels, radio, multiple motors, or autonomous roaming.

When every Build It box is checked, add your name to Ready-for-Check. Keep Leveling Up until you are called.

06

SHOW WHAT YOU KNOW

Checkpoint

Bring your reactive system and open your code when you are called. The checkpoint is individual.

Check 1 — Trace Sense → Think → Act

Trace Light Sensor → sensor value → threshold decision → LED response. Identify Sensor Port 1, LED Port 1, the current value, your threshold, and why that threshold makes sense.

Check 2 — Explain the Decision

Explain what the sensor measures, what the value and threshold mean, when IF is true, what ELSE does, and why the system keeps checking repeatedly.

Check 3 — Change It

Change the threshold, reverse the LED responses, change one brightness, or change the comparison direction. Then predict → change → download → test → explain.
